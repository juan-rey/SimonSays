# SimonSays 帮助指南

## 概述
SimonSays 是一款适用于 Windows 的文字转语音（TTS）助手，由 Juan Rey Saura 创建。它最初是为渐冻症（ALS）患者和其他无法再说话的人设计的工具，让他们无需离开正在电脑上做的事情就能快速交流。随着时间推移，人们发现同样的设计也适合作为通用的辅助沟通（AAC，扩大和替代沟通）工具，帮助任何说话困难或无法说话的人；例如因构音障碍、喉切除、言语失用症、中风或脑损伤而说话困难的人。它针对快速说话、短语库以及在文本中插入播放声音进行了优化，支持多种语言、可调节的语音，以及为高效沟通而设计的功能。

SimonSays 利用 Windows 任务栏上的空白区域，只需点击几下即可快速访问十几个常用（且可自定义）短语类别。由于它从不遮挡你的其他窗口，你可以留在浏览器、文档或视频通话中，随时开口说话：用键盘、用鼠标，或借助眼动仪完全不用手。

使用场景：
- 在大量使用多个 Windows 应用程序的同时不中断沟通。
- 言语治疗师为言语障碍者制作的板面。
- 使用 [Virtual CABLE](https://vb-audio.com/Cable/) 参加线上会议（参见[在线上会议中使用 SimonSays](#在线上会议中使用-simonsays)）。

SimonSays 并不打算取代 Mind Express、TD Communicator、Grid 3 或 OptiKey 等完整的沟通软件，也不取代通常随之提供的专业评估和支持。它做的是一件更具体的事：在你继续使用其他应用程序时，从任务栏快速说话。它可以与这些程序同时运行；例如，OptiKey 或其他眼控软件可以移动光标，而 SimonSays 朗读你的短语。

SimonSays 是开源且免费的（自由意义上的自由，而不仅仅是价格上的免费），并将一直如此：任何人都可以使用、研究、改编和分享它。它没有广告，也不收集任何数据。

SimonSays 即将推出 1.0 版。在这个里程碑之前，它需要有人在日常生活中使用自己的语音、板面和眼动仪来试用它：如果有什么出错、用起来不方便或缺少什么，请告诉我们（参见[反馈、支持和隐私](#反馈支持和隐私)）。每一条反馈都有帮助。

## 入门
1. 启动 SimonSays。它会出现在 Windows 任务栏的空白处，并在通知区域添加一个图标。任务栏可以位于屏幕的底部、顶部、左侧或右侧：
   - 当任务栏图标居中时，SimonSays 位于任务栏的最开头（左端，或侧边任务栏的顶部）。当图标靠左对齐时，它位于通知区域的正前方。
   - 在较小（较窄）的任务栏上，SimonSays 栏会变矮，字体变小，两个快速访问按钮并排显示。在屏幕左侧或右侧的任务栏上，各控件会上下堆叠。
   - 类别窗口在任务栏旁边打开，`类别` 按钮上的箭头指示它向哪一侧打开。
   - 如果在 SimonSays 运行时移动任务栏或调整其大小，它会在几秒内跟随过去。
2. 要说话，你可以：
   - 点击栏上的文本框（或将视线停留在上面）：任务栏旁会打开一个更大的输入框。输入文字后按 `Enter` 朗读；输入框关闭，焦点移到 `播放>`，所以按 `空格` 会再次朗读（或停止）。`Esc` 关闭输入框而不朗读，并返回你之前使用的窗口；文字留在栏中，`播放>` 可以再次朗读。
   - 在类别窗口中点击一个或多个已保存的短语。
3. 播放时按钮显示 `>`，表示正在播放。再次按下即可立即停止。

![任务栏上的 SimonSays 栏](img/bar.png)

在 `类别` 按钮旁边，有两个小的**快速访问按钮**，只需一次点击即可完成原本需要用快捷键或通知区域菜单才能完成的两件事：

- 📂 打开保存在电脑上的板面；这与 `F9` 的导入相同，但会从你的板面文件夹（`%LocalAppData%\SimonSays\boards\`）开始，导出和下载的板面都保存在那里（参见[导入和导出类别](#导入和导出类别)）。
- ⚙️ 打开设置，与 `F2` 相同。

可以在设置（`F2`）中通过 `显示快速访问按钮和菜单` 隐藏这两个按钮，为输入框留出更多空间。同一设置也会关闭类别窗口的右键菜单。

如果 SimonSays 处于隐藏状态，点击通知区域中的图标即可再次显示它。

## 类别窗口
![显示默认短语的类别窗口](img/categories.png)

- 使用 `类别` 按钮打开它。可以调整其大小，或在设置中启用 `记住分类窗口大小` 以保持大小。
- 在上方列表中选择类别，在下方列表中选择短语。
- 如果启用了 `选择短语时立即朗读`，单击短语会自动朗读；否则短语会载入主输入框而不朗读。
- 双击空白区域或窗口边缘，可将窗口大小调整到刚好容纳所有类别和短语。
- 拖动窗口的空白区域可移动窗口，按 `Esc` 可隐藏窗口。
- 用 `F12` 和 `F11` 放大和缩小（参见[快捷键](#快捷键)）。
- 右键单击按钮或空白区域（或按 `Shift + F10` 或菜单键），会打开包含 `粘贴`、`缩小`、`放大`、`重置缩放`、`帮助`、`设置`、`视线 / 注视点击...`、`隐藏` 和 `退出 SimonSays...` 的菜单，每项都显示其快捷键。第一项显示板面标题（如果没有标题则为 `未命名板面`）；选择它可查看板面的署名、语言以及包含多少类别和短语。只有在设置中启用 `显示快速访问按钮和菜单` 时才会显示该菜单。
- 在类别或短语按钮上，菜单还为该按钮提供 `编辑...`、`左移`、`右移`、`添加新类别...` 或 `添加新短语...`，以及 `删除类别...` 或 `删除短语...`，无需先选中它；在类别上，`导出类别...` 会询问只保存该类别还是整个板面。当按钮是当前选择时会显示快捷键 `F4` 到 `F8`，因为这些按键作用于当前选择。在空白区域，菜单提供 `添加新类别...`，会在末尾添加一个类别；这也是从空板面开始的方式。
- 类别和短语之间的横条显示主要快捷键的提示（如果板面有说明文字，则显示说明文字）。

![短语按钮的右键菜单](img/menu.png)

## 默认短语
SimonSays 在其 18 种语言中都附带一套现成的类别和短语，排列顺序让最常用的短语只需最少的选择：

- 👋🏻 常见问候
- 🗣️ 会话短语
- 🚨 紧急用语
- 🤲 照护与舒适
- 🏥 健康用语
- 🏠 家庭与家
- 👥 社交用语
- ⏰ 时间与日期
- 💼 商务用语
- ✈️ 旅行用语
- 🔊 声音

每种语言都有自己的类别和短语：在设置（`F2`）中更改语言时，类别窗口会切换到该语言的板面，你在一种语言中所做的更改不会影响其他语言。

短语使用 Windows 中安装的语音朗读。如果没有为你的语言安装语音，短语仍会显示，但可能会用其他语音朗读（参见[故障排除](#故障排除)）。

你可以修改默认短语，或之后再恢复它们；参见[编辑类别和短语](#编辑类别和短语)和[恢复默认短语](#恢复默认短语)。

## 快捷键
- `F1`：打开帮助
- `F2`：打开设置
- `F3`：视线 / 注视点击设置
- `Enter`：朗读输入框中的文字
- `Esc`：隐藏类别窗口
- `F11` / `Ctrl -`：缩小（类别窗口）
- `F12` / `Ctrl +`：放大（类别窗口）
- `Ctrl + 0`：重置缩放
- `Shift + F10` 或菜单键：打开类别窗口的菜单（与右键单击相同）
- 在 `播放>` 上按 `空格`：再次朗读文字，或在播放时停止

编辑类别、短语和板面的快捷键列在[编辑类别和短语](#编辑类别和短语)中。

## 设置 (F2)
打开设置（`F2`）可以控制以下内容。设置分为两栏。

![设置窗口](img/settings.png)

**左栏**
- **默认文本**：开启或关闭 `自动插入默认文本`，并自定义默认短语。
  - `显示触摸键盘`：打开输入框时同时打开屏幕触摸键盘；它会放在输入框旁边、远离任务栏的一侧。
- `显示快速访问按钮和菜单`：在主窗口的 `类别` 按钮旁显示 📂（打开板面）和 ⚙️（设置）按钮（参见[入门](#入门)），并启用类别窗口的右键菜单（参见[类别窗口](#类别窗口)）。关闭此项可将它们全部隐藏，为输入框留出更多空间。
- **类别窗口**：
  - 选择后 `自动最小化分类窗口`。
  - `记住分类窗口大小`。
  - `自动调整分类窗口大小以适应内容`：每次载入类别和短语时，都会调整类别窗口大小以容纳它们；例如在启动时、更改语言后或导入后。
- `视线 / 注视点击...`：在设置之上打开[视线 / 注视点击](#视线--注视点击-f3)设置，设置窗口保持打开并保留你的更改。在那里所做的更改会在你按该窗口中的 `确定` 时保存，即使之后你在设置中按了 `取消`。

**右栏**
- **语言**：选择界面语言（English、Español、العربية、Euskara、Català、简体中文、Français、Galego、Deutsch、עברית、हिन्दी、Italiano、日本語、한국어、Português、Português (Brasil)、Русский、Valencià）。每种语言也有自己的类别和短语（参见[默认短语](#默认短语)）。
- **语音**：选择与你的语言匹配的已安装 SAPI 语音。
- **音量/语速**：调整 `音量 (10-100)` 和 `语速 (-10 到 10)`。
- `测试语音`：试听所选语音（通过 `声音输出` 中选择的设备）。
- `声音输出`：SimonSays 播放语音和声音的位置：`Windows 默认`（通常选择）或任何已连接的设备。虚拟音频线排在最前面，这正是[线上会议](#在线上会议中使用-simonsays)所需要的。如果所选设备未连接，SimonSays 会通过 Windows 默认设备播放并提醒你一次；你的选择会被保留，显示为 `（未连接）`，设备重新连接后立即再次使用。
- `侦听设置...`：打开 Windows 录制设备，你可以在其中为虚拟音频线开启**侦听此设备**（参见[在线上会议中使用 SimonSays](#在线上会议中使用-simonsays)）。
- **播放行为**：
  - `选择短语时立即朗读`（单击即自动朗读）。
  - `停止上一次播放`：开始新短语前自动停止正在进行的播放。
  - `播放时提高 SimonSays 音量`：说话时提高 SimonSays 所用设备（参见 `声音输出`）的音量，结束后恢复之前的音量。
  - `播放时临时降低其他音频`：说话时降低其他应用程序的音量，结束后恢复。

**底部**
- `帮助`（左下角，或在设置打开时按 `F1`）以 `语言` 列表中所选的语言打开本帮助；设置保持打开并保留你的更改。
- `确定` 保存更改；`取消` 放弃更改。

默认情况下，`选择短语时立即朗读`、`自动最小化分类窗口`、`自动调整分类窗口大小以适应内容`、`播放时提高 SimonSays 音量` 和 `播放时临时降低其他音频` 处于开启状态，`停止上一次播放` 处于关闭状态。

## 视线 / 注视点击 (F3)
将视线（或鼠标光标）在短语和按钮上停留一段设定的时间，即可不用手激活它们。这是一项新功能：需要测试和反馈；请通过通知区域菜单中的 `反馈` 选项告诉我们它在你的眼动仪上的使用效果。

支持的配置：
- **任何移动鼠标光标的眼控软件**（Irisbond EasyClick、Tobii Dynavox Computer Control、Windows 眼动控制的光标模式、OptiKey）：注视点击跟随光标。
- **直接读取视线（无需移动光标）**：Irisbond Hiru（HID 模式）以及通过自带软件使用的 Tobii 眼动仪；已在 Tobii Eye Tracker 4C、Tobii Eye Tracker 5 和 Tobii Dynavox PCEye 5 上验证。
- **Tobii Eye Tracker 5**：它当前的软件只安装 64 位引擎，因此 SimonSays 通过安装在旁边的小型辅助程序 `SimonSaysGaze64.exe` 读取它。辅助程序只在需要时启动，没有窗口，随 SimonSays 一起关闭，并且视线数据只留在你的电脑上：从不保存，也不会发送到任何地方。
- **Tobii Eye Tracker 4C 和 Eye Tracker 5 的许可**：Tobii 对这些眼动仪的最终用户许可不允许医疗用途，包括在医院和其他医疗机构中使用。Tobii Dynavox 设备（如 PCEye 5）有其自己的许可条款。
- **Tobii Eye Tracker 4C 软件**：SimonSays 通过 Tobii Core 读取 4C。如果在同一台电脑上插入 Eye Tracker 5，Windows 会安装 Tobii Experience，它会关闭 Tobii Core，导致 4C 停止工作。要再次使用 4C，请重新安装 Tobii Core；推荐版本为 `Tobii_Eye_Tracking_Core_v2.13.1.7294_x86.exe`，可从 [Tobii 入门页面](https://gaming.tobii.com/getstarted/)获取。

注视点击适用的位置：
- SimonSays 栏、类别窗口及其中的短语和类别按钮。
- SimonSays 自身窗口和问题对话框中的按钮：设置、视线 / 注视点击窗口、添加、编辑和预览对话框，以及所有确认按钮，例如 `是` / `否` 或 `确定` / `取消`。这些按钮以你的语言显示，并在窗口打开约四分之三秒后才开始响应注视，这样在你目光所及之处弹出的问题就不会自己被回答。
- 直接读取视线时，你正在注视的按钮会像在鼠标下一样亮起，让你在进度开始前就能看清将要选择的内容。眨眼会保持高亮；移开视线则取消高亮。

![视线 / 注视点击窗口](img/dwell.png)

打开视线 / 注视点击设置（`F3`、通知区域菜单，或设置中的 `视线 / 注视点击...` 按钮）可以配置：
- **激活模式**：选择以下选项之一：
  - `自动`：检测现有设备，并根据情况使用鼠标光标或视线检测启用注视点击。仅有后台运行的 Tobii 软件（安装后一直运行）不会启用光标注视；只有在 Tobii 眼动仪确实在追踪视线时才会使用它。
  - `鼠标光标`：始终使用鼠标光标启用注视点击。
  - `HID 眼动仪`：始终使用视线检测启用注视点击（HID 模式的 Irisbond Hiru，或 Tobii 眼动仪）。只有你的视线才能激活按钮：在没有视线数据传来时（追踪已关闭或眼动仪已拔出），任何东西都不会因注视而激活，鼠标照常工作。
  - `关闭`：始终关闭注视点击。
  - **锁定延迟**：你的视线（或光标）必须在按钮上停留多久（以毫秒计）后进度条才开始（默认 250）。这样，目光扫过按钮时不会出现任何进度；按钮会在锁定延迟加上注视时间之后激活。设为 0 则进度立即开始。
  - **注视时间**：注视某个元素时触发点击所需的时长（以毫秒计）（默认 500）。注视期间会显示进度指示器。
  - **容差半径**：视线的容差（以像素计），允许眼睛轻微移动而不中断注视。
  - **冷却时间**：激活后的一段毫秒数，在此期间注视点击不能再次触发（防止意外重复点击）。
  - **进度颜色**：注视进度指示器的颜色（默认为 Windows 主题色）。
  - **移开后才能再次通过注视激活**（默认开启）：注视点击之后，在指针或视线离开该位置（超出容差半径）或你短暂移开视线之前，任何按钮都不能再次通过注视激活。停留在按钮上只会激活一次，因此长句在说完之前不会被重复。鼠标点击不受影响。
  - **检测你使用追踪器的方式**：两个按钮，帮助应用程序检测你是在用眼动仪移动鼠标光标，还是只是点击按钮。
  - **已检测到**：显示检测到的设备类型以及相关软件的更多信息。
  - `保存诊断报告...`（位于“已检测到”下方）：将关于你的眼动仪及其软件的报告写入 `hid_dump.txt` 并打开其所在文件夹，以便你发送给支持人员。
  - `重置` 按钮（左下角）将所有注视设置恢复为默认值。
  - `确定` 按钮保存更改；`取消` 放弃更改。

## 在线上会议中使用 SimonSays
SimonSays 可以直接在视频通话（Teams、Zoom、Google Meet……）中说话，让其他参与者听到你的短语，就像来自你的麦克风一样。你需要一条虚拟音频线，例如免费的 [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)：

1. 安装虚拟音频线，如有提示请重启 Windows。
2. 将 SimonSays 的声音发送到音频线：打开设置（`F2`），在 `声音输出` 中选择 `CABLE Input`（虚拟音频线排在最前面）。按 `测试语音` 检查：你应该不再从扬声器听到它，因为声音现在进入了音频线。
3. 在会议应用程序中，选择 `CABLE Output` 作为麦克风。
4. 如果你自己也想听到 SimonSays，在设置中按 `侦听设置...`。Windows 录制设备会打开：选择 `CABLE Output`，打开**属性 → 侦听**，勾选**侦听此设备**，在**通过此设备播放**中选择你的扬声器或耳机，然后按 `确定`。这只需要做一次。

SimonSays 无法替你开启**侦听此设备**：这是音频线录制端的设置，Windows 只允许你自己更改，所以 `侦听设置...` 会直接带你到正确的窗口。

须知：
- 请将 Windows 默认播放设备保留为你的扬声器或耳机，而不是 `CABLE Input`。如果**侦听此设备**播放到“默认播放设备”，而该默认设备就是音频线，声音就会回流到音频线中。
- 如果会议中能听到你的短语，却听不到音效（掌声、门铃），那是会议应用程序的降噪功能把它们去掉了；请在应用程序中降低或关闭降噪。
- 如果音频线被卸载或断开，SimonSays 会通过 Windows 默认设备播放并提醒你一次；音频线重新可用后，它会立即切回音频线。
- 要准备好通话用的短语，请添加**会议模板**类别：按 `F9` 或 📂 按钮，打开以你的语言命名的板面（简体中文为 `SimonSays_会议模板_(简体中文).ssc`）。其中包括问候语、“你能听到我吗？”、简短说明你是通过程序说话、是 / 否、同意 / 不同意、请对方重复或说慢一点，以及道别语。编辑它，添加适合你自己会议的短语。
- 作为第 2 步的替代方法，你仍然可以使用 Windows 的按应用设置（**设置 → 系统 → 声音 → 音量合成器**）来路由 SimonSays，同时将 `声音输出` 保留为 `Windows 默认`。SimonSays 只有在播放过声音后才会出现在该列表中。

## 编辑类别和短语
本节及后续各节面向护理人员、言语治疗师和高级用户，他们会更改板面的类别、短语、声音和外观。每次更改都会立即保存（参见[撤销更改](#撤销更改)）。

### 使用哪个编辑器
- **在 SimonSays 中**：日常更改；重命名、添加、移动或删除类别和短语，为它们设置表情符号，添加声音，粘贴短语列表，或调整颜色。本节其余部分介绍具体做法。
- **在 [SimonSays Web](https://github.com/juan-rey/simonsays-web) 中**：更大规模的板面工作，在那里要容易得多：用 AAC 图符制作的板面（它可以搜索 ARASAAC 图符库）、自定义图标图片，以及带有颜色、尺寸和布局的样式化板面。特别推荐用它来设计 **Fitzgerald Key** 板面，其中每个词组都有自己的颜色。它是一个可视化编辑器，直接在浏览器中打开和保存 `.ssc`/`.ssz` 板面，无需上传；完成后，用 `F9` 或 📂 按钮将板面导入 SimonSays。这也是在其他平台上使用 SimonSays 板面的方式。

编辑快捷键（类别窗口）：
- `F4`：编辑当前选择
- `F5` / `F6`：在列表中移到上一个 / 下一个选择
- `F7`：在当前选择之后添加（根据上下文添加类别或短语）
- `F8`：删除当前选择
- `F9`：导入类别
- `F10`：导出类别
- `Ctrl + F4`：编辑板面样式（参见[自定义外观](#自定义外观-板面和类别样式)）
- `Ctrl + F8`：删除所有类别及其短语（会要求确认两次）
- `Ctrl + V` 或 `Shift + Insert`：将复制的文本作为短语添加，每段一个短语（参见[管理短语](#管理短语)）
- 将 `.txt`、`.ssc` 或 `.ssz` 文件拖到窗口上：将 `.txt` 添加为新类别，或像 `F9` 一样导入板面（参见[管理类别](#管理类别)）

> **提示：** 在使用 `Ctrl + F8` 或导入整个板面（`F9`）之前，请先导出你的板面（`F10`），以便日后找回。

### 管理类别
- 重命名：选择类别 → （快捷键：`F4`）`更改类别名称` → 修改名称 → `确定`。
- 移动选择：浏览列表时用 `F5`/`F6` 移到上一项/下一项。
- 添加：选择一个类别 → （快捷键：`F7`）`添加新类别` 对话框 → 输入名称 → `确定`。
- 删除：选择类别 → （快捷键：`F8`）`删除类别`；确认删除该类别及其短语。
- 从文本文件添加：将 `.txt` 文件拖到类别窗口 → 会创建一个以文件名命名的类别，每段一个短语（段落之间用空行分隔） → 检查预览 → `确定`。可以一次拖入多个文件；每个文件都有自己的预览。如果文件名与现有类别同名，则会被拒绝。
- 拖动打开板面：将 `.ssc` 或 `.ssz` 文件拖到类别窗口 → SimonSays 会询问是否导入；选择 `是` 后，与 `F9` 的导入方式相同（参见[导入和导出类别](#导入和导出类别)）。如果文件包含整个板面，它会替换当前板面，替换前会先将当前板面保存为 `backup.ssz`。可以同时拖入文本文件和板面文件；它们会依次处理。从文件资源管理器中打开（双击）`.ssc` 或 `.ssz` 文件也会询问同样的问题。

#### 设置或更改类别图标
每个类别都可以在按钮上显示一个表情符号或自定义图片文件（`.ico`、`.png` 或 `.jpg`）。在添加或编辑对话框中使用分隔前缀 `##` 指定图标：

```
<图标>##<类别名称>
```

- **表情符号**：输入表情符号（一个或多个），后跟 `##` 和名称。
  - 示例：`🙂##问候`
- **图标文件**（`.ico`、`.png`、`.jpg`）：输入文件名或完整路径，后跟 `##` 和名称。不带文件夹的文件名会按[声音和图标文件的查找顺序](#声音和图标文件的查找顺序)中所述的方式查找。
  - 示例：`C:\icons\smile.png##问候`
- **无图标**：只输入类别名称，不加 `##` 前缀。
  - 示例：`问候`

> 注意：基于文件的图标仅支持 `.ico`、`.png` 和 `.jpg` 文件。其他扩展名会被忽略，不显示图标。PNG 图片会保留透明度；非常大的图片在载入时会自动缩小。

### 管理短语
- 编辑：选择短语 → （快捷键：`F4`）`编辑短语` → 更新文本 → `确定`。
- 移动选择：用 `F5`/`F6` 移到上一个/下一个短语。
- 添加：选择一个短语 → （快捷键：`F7`）`添加新短语` → 输入文本 → `确定`。
- 删除：选择短语 → （快捷键：`F8`）`删除短语`；确认。
- 一次添加多个：复制用空行分隔短语的文本 → 选择一个短语（或类别） → `Ctrl + V` → 检查预览 → `确定`。短语会添加在所选短语之后，或类别末尾。段落内的换行会变成空格，`##` 图标标记和 `::` 音频标记的作用与 `添加新短语` 对话框中相同。
- 添加声音：将一个或多个 `.wav` 或 `.mp3` 文件拖到类别窗口 → 检查预览 → `确定`。每个文件都会成为一个以文件名命名的声音短语，添加在所选短语之后（或所选类别的末尾），文件会被复制到板面的资源文件夹中，以便导出板面时一同带走。现有文件绝不会被覆盖：如果已有同名但不同的声音，新文件会保存为 `name (2).wav`。

#### 设置或更改短语图标
短语与类别使用相同的图标前缀约定，在短语文本前加上可选的 `##` 分隔符：

```
<图标>##<短语文本>
```

- **表情符号**：`👍##听起来不错！`
- **图标文件**：`C:\icons\check.png##听起来不错！`
- **无图标**：`听起来不错！`

短语可以包含音频文件（参见[混合语音和声音](#混合语音和声音)）。要组合图标、文本和音频，请使用以下格式：

```
<图标>##<短语文本>::<音频文件>
```

- 示例：`🔔##注意::alert.mp3`

`##` 前缀和 `::` 后缀都是可选且相互独立的；你可以使用任意组合：
- 仅图标前缀：`🔔##注意`
- 仅音频后缀：`注意::alert.mp3`
- 两者都有：`🔔##注意::alert.mp3`
- 两者都无：`注意`

## 混合语音和声音
- 使用分隔符 `♫` 在文本中嵌入音频文件名：
  - 示例：`你好 ♫doorbell.mp3♫，请稍等。`
  - 分隔符之外的文字会被朗读；分隔符之内的文字被视为声音文件并在该位置播放。
- 支持的音频：`.wav` 和 `.mp3`。MIDI 文件（`.mid`、`.midi`）可以写在短语中，但不会播放；请将其转换为 `.wav` 或 `.mp3`。
- 使用程序可以访问的绝对路径或相对路径。确保分隔符成对出现，以免后面的文字被当作音频。
- 要输入 `♫`，可以从本帮助中复制，或选择一个带声音的短语：它的 `♫…♫` 标记会放入输入框，你可以在其前后添加文字。

### SimonSays 自带的声音
这些声音随 SimonSays 一起安装，可以在任何文本或短语中按名称使用；例如在输入框中输入 `♫laugh.mp3♫`，或用 `做得好！::applause.mp3` 制作一个标签为“做得好！”并播放掌声的短语按钮：

`ahem.mp3`, `alert.mp3`, `applause.mp3`, `aww.mp3`, `beep.mp3`, `boo.mp3`, `call_bell.mp3`, `censor.mp3`, `doorbell.mp3`, `drumroll.mp3`, `evil_laugh.mp3`, `fail.mp3`, `hmmmm.mp3`, `kisses.mp3`, `laugh.mp3`, `mmm-hmm.mp3`, `nuh-uh.mp3`, `phone_ring.mp3`, `rimshot.mp3`, `scream.mp3`, `shots.mp3`, `sigh.mp3`

### 声音和图标文件的查找顺序
当声音或图标的文件名不包含驱动器号或完整路径时，SimonSays 会按以下顺序查找，并使用第一个找到的文件：

1. **当前板面的资源子文件夹**：如果板面样式设置了 `title` 或 `resource-folder`，则为资源文件夹中属于它自己的子文件夹（参见[自定义外观](#自定义外观-板面和类别样式)）。
2. **资源文件夹**：`%LocalAppData%\SimonSays\resources\`（板面图标和声音的默认位置；导入的 `.ssz` 包会将文件安装在这里）。
3. **SimonSays 数据文件夹**：`%LocalAppData%\SimonSays\`（为早期版本在资源文件夹出现之前放在这里的文件而保留的备用位置）。
4. **工作目录**：进程的当前工作目录（仅当它与程序文件夹不同时才会查找）。
5. **程序文件夹**：包含 `SimonSays.exe` 的文件夹。

如果在这些位置都找不到文件，则使用内置的备用声音（图标则不显示）。

> **提示：** 建议将自定义的声音和图标文件放在 `%LocalAppData%\SimonSays\resources\` 中；它们在应用程序更新后仍会保留，并且属于各个用户。带有 `title` 或 `resource-folder` 样式的板面会自动在那里获得自己的子文件夹，使其文件与其他板面的文件分开。

## 自定义外观 (板面和类别样式)
你可以更改类别窗口及其按钮的颜色、大小和样式；例如用来制作 Fitzgerald Key 这类按颜色编码的沟通板面。样式是可选的：没有样式时，窗口保持默认外观。

> **提示：** 下面的所有内容都可以在 SimonSays 中输入，适合做小幅调整。如果要设计一个完整的样式化板面或图符板面，推荐使用 [SimonSays Web](https://github.com/juan-rey/simonsays-web)：你可以边做边看效果，它会替你写好这些样式（参见[使用哪个编辑器](#使用哪个编辑器)）。

样式是一组 `property:value;` 对。值可以是：
- **颜色**：十六进制 `#RRGGBB`，例如 `#FFD966`。
- **尺寸**：像素数（`96`）或默认值的百分比（`120%`）。
- **关键字**：例如 `left`、`right`、`top`、`bottom`、`smart`、`normal`、`bold`。
- **文本**：字体名称，或说明文字、标题、署名的文本。

应用程序无法识别的内容（拼错的属性或无效的值）都会被直接忽略，因此样式永远不会弄坏窗口。

### 设置单个类别的样式 (编辑窗口)
选择一个类别并按 `F4`（编辑），然后在名称后添加 `::` 和样式：

```
<图标>##<类别名称>::<property>:<value>;<property>:<value>;
```

- 示例：`🧍##人物::background:#FFD966;` 会把“人物”按钮涂成黄色。类别的颜色**也会应用到其中的短语**，所以一行就能为整个词组上色：这正是 Fitzgerald Key 板面的核心。
- 类别样式可以为类别按钮设置 `background` 和 `text-color`，也可以设置任何加上 `phrase-` 前缀的短语属性（见下文），例如 `phrase-corner-radius:8;`。

### 设置整个板面的样式 (`$$board`)
整体外观（窗口背景、分隔线，以及所有类别和短语按钮的默认值）是一种**板面样式**。它保存在保留的类别名称 `$$board` 下（你不能用以 `$$` 开头的名称命名自己的类别）。

- 在类别窗口中按 `Ctrl + F4` **编辑它**。编辑器每行显示一个 `property:value;`。用 `确定` 确认后，新样式会被应用，SimonSays 会询问“要撤销更改吗？”：选择 `确定` 返回之前的样式，或选择 `取消` 保留新样式。
- 通过导入带样式的类别文件（`.ssc` / `.ssz`）**获取样式**。导入包含板面样式的文件时，SimonSays 会在替换你的样式前询问，并在导入消息中显示板面的 `title` 和 `credits`（如果有）。如果文件的板面样式只设置了 `title`、`credits`、`language` 或 `resource-folder`，就不会改变任何可见内容，因此 SimonSays 不会询问：如果它只包含一个类别，该类别会被添加，你的外观保持不变；如果它包含整个板面，则会像任何整个板面一样，连同外观一起替换你的板面。

### 样式属性
- **整个窗口**：`background`、`separator-color`、`text-color`、`font-name`、`font-size`、`text-weight`、`caption`（显示在分隔线之间的说明文字）、`title` 和 `credits`（导入板面时显示）、`language`（板面所针对的语言，例如 `language:Chinese (Simplified)`；当设置的语言不同时，SimonSays 会拒绝导入该板面，并告诉你应在设置（`F2`）中切换到哪种语言）。
- **所有类别按钮**（`category-` 前缀）和**所有短语按钮**（`phrase-` 前缀）：`background`、`text-color`、`width`、`height`、`corner-radius`、`border-width`、`margin`、`icon-position`（`left`/`right`/`top`/`bottom`/`center`）、`icon-size`、`font-name`、`font-size`、`text-weight`、`text-layout`。

将 `icon-position` 设为 `center` 时，图标位于按钮中央，文字会被隐藏（仅图标的按键）；如果想让图标在上、名称在下，请使用 `top`。如果确实想在居中的图标上显示文字，请添加明确的 `text-layout`（例如 `text-layout:bottom`），文字就会显示在该位置。

`text-layout` 接受一个水平关键字（`left`/`center`/`right`）和/或一个垂直关键字（`top`/`middle`/`bottom`），或 `smart`。默认值为 smart：文字在图标留出的空间中居中（图标在上 → 说明文字在下方居中；没有图标时在整个按钮中居中）。

### 示例: 按颜色编码的 Fitzgerald Key 板面
要为六个词组上色，请编辑每个类别（`F4`）并给它一种背景色。以下是在编辑对话框中输入的确切字符串：

```
🧍##人物::background:#FFD966;
🏃##动作::background:#93C47D;
📏##描述::background:#6FABDC;
🍎##名词::background:#F6B26B;
🕒##其他::background:#FFFFFF;
👋##社交::background:#B4A7D6;
```

每种颜色也会为该类别中的短语上色，因此整个板面都按颜色编码。整个板面范围的调整（例如把每个类别的表情符号放在上方、名称放在下方，以及为分隔线上色）来自板面样式（`Ctrl + F4`），例如：

```
category-icon-position:top;separator-color:#B4A7D6;
```

如果要制作完整的 Fitzgerald Key 板面，让每个按键都有图符、短语按词组排列，请在 [SimonSays Web](https://github.com/juan-rey/simonsays-web) 中制作，然后用 `F9` 导入。

样式会随你的类别一起移动：导出（`F10`）时会包含样式，导入（`F9`）时会带上样式，因此样式化的板面可以作为单个文件分享。

## 导入和导出类别
板面以 `.ssc` 文件（类别和短语）或 `.ssz` 文件（同上，外加它们使用的声音和图标文件，合为一个文件）的形式分享。你也可以用 [SimonSays Web](https://github.com/juan-rey/simonsays-web) 在浏览器中可视化地创建和编辑它们。

- **导出**（`F10`）：在询问时选择导出所有类别或仅导出所选类别；保存对话框默认在 `%LocalAppData%\SimonSays\boards\` 中打开，但你可以保存到任何位置。当你的类别或短语使用 SimonSays 能找到的声音或图标文件时，它会自动保存为 `.ssz`（不包含 `.mid`/`.midi` 声音）。导出所有类别时包含板面样式；导出单个类别时只包含该类别的样式。成功或失败的消息以所选语言显示。
- **导入**（`F9`）：选择一个 `.ssc` 或 `.ssz` 文件。
  - 包含**多个类别或板面样式**的文件是一个整个板面：它会**替换当前语言的所有类别和短语**。你之前的板面会先保存为 `backup.ssz`（参见[撤销更改](#撤销更改)）。
  - 只包含**一个类别**的文件会被添加到你的板面；如果已存在同名类别，会询问你是否覆盖。当文件只为其板面命名（`title`、`credits` 或 `language`，没有颜色、尺寸或字体）时也是如此：这些信息绝不会替换你的板面或其外观。
  - `.ssz` 中的声音和图标文件会安装到资源文件夹，类别窗口会调整大小以适应导入的板面。成功或失败的消息以所选语言显示。

## 撤销更改
SimonSays 会立即保存每一次更改，没有通用的撤销命令。返回之前状态的方法如下：

- **撤销导入**：在导入替换你的板面之前，SimonSays 会把之前的板面保存为 `%LocalAppData%\SimonSays\boards\` 中的 `backup.ssz`。要撤销导入，按 `F9` 并选择 `backup.ssz`：你之前的板面会原样恢复，包括类别和外观，不会再提出其他问题。只保留最近一次被替换的板面：每次新导入整个板面都会覆盖备份。
- **撤销板面样式的修改**：用 `Ctrl + F4` 编辑板面样式后，SimonSays 会询问“要撤销更改吗？”；选择 `确定` 即可返回之前的样式。
- **撤销类别或短语的修改**：用 `F4`、`F7` 或 `F8` 所做的更改无法自动撤销。在对重要的板面做大的更改之前，请先导出它（`F10`）；之后导入该文件（`F9`）即可回到那个时间点。

### 恢复默认短语
SimonSays 从不覆盖你自己的类别和短语，因此更新带来的新默认短语只会出现在你尚未使用过的语言中。你可以随时恢复内置的类别和短语；例如重新开始，或获取更新中的新短语。这会**替换当前语言的整个板面**：

1. 点击 `类别` 旁边的 📂 按钮（或在类别窗口中按 `F9`）。板面文件夹会打开。
2. 选择你的语言的默认短语板面；简体中文为 `SimonSays_默认短语_(简体中文).ssc`（其他语言的文件名形式相同，使用相应语言；例如 `SimonSays_default_phrases_(English).ssc`）。
3. 确认导入。你当前的板面会先保存为 `backup.ssz`，所以你仍然可以找回它（参见[撤销更改](#撤销更改)）。

这个板面始终包含你正在运行的 SimonSays 版本的默认短语：SimonSays 会在启动时和更改语言时更新板面文件夹中的这个文件。如果你想保留自己的板面，请先用你选择的名称导出它（`F10`）；`backup.ssz` 会在下一次导入时被覆盖。

如果板面文件夹中缺少该文件，还有最后一种办法：退出 SimonSays（通知区域菜单 → `退出`），打开注册表编辑器（`regedit`），删除 `HKEY_CURRENT_USER\SOFTWARE\SimonSays\Phrases\` 下以你的语言英文名称命名的项（例如 `Chinese (Simplified)`），然后重新启动 SimonSays。该语言的默认类别和短语会重新创建，不会有备份。

对于 `Portuguese (Brazil)`：如果同时存在 `Portuguese` 项，SimonSays 会将该板面复制到 `Portuguese (Brazil)`，而不是创建巴西葡萄牙语的默认短语，因此请同时删除 `Portuguese` 项（如果你在使用它，请先导出）。

## SimonSays 在哪里保存你的文件
- **类别、短语和设置**保存在 Windows 注册表的 `HKEY_CURRENT_USER\SOFTWARE\SimonSays` 下（每种语言的板面在 `Phrases\<Language>` 下）。
- `%LocalAppData%\SimonSays\resources\`：你的声音和图标文件，以及从 `.ssz` 板面安装的文件；样式设置了 `title` 或 `resource-folder` 的板面会有自己的子文件夹。
- `%LocalAppData%\SimonSays\boards\`：导出板面的默认文件夹、自动备份 `backup.ssz`，以及 SimonSays 自带的板面：每种语言的默认短语，以及可以用 `F9` 或 📂 按钮添加到板面中的现成类别：是 / 不是、疼痛和身体、游戏、提问、日常护理、会议模板和听力检查（以你的语言命名），以及适用于任何语言的 `Spelling_NATO`、`Alert_tones` 和 `Morse_code`。每一个都会添加一个类别，而不会替换你的板面。每当你的语言的默认板面缺失或发生变化时，你的语言的板面会在启动时以及在设置中更改语言时复制到那里，并替换文件夹中的副本；因此，请用新名称保存你编辑过的板面。
- `%LocalAppData%\SimonSays\debug\`：支持人员可能会要求提供的诊断文件（例如 `hid_dump.txt`）。

要打开其中某个文件夹，请将其路径（例如 `%LocalAppData%\SimonSays`）粘贴到文件资源管理器的地址栏中。

## 故障排除
- **语音初始化失败**：确认已安装 SAPI 并且有兼容的语音。
- **没有适合我语言的语音，或短语口音不对**：SimonSays 使用 Windows 中安装的语音。在 Windows 设置（**时间和语言 → 语音 → 管理语音**）中为你的语言添加语音，然后在 SimonSays 的设置（`F2`）中选择它。某些较新的 Windows“自然”语音可能无法供其他应用程序使用。
- **没有声音播放**：检查文件路径和扩展名，以及 `♫` 分隔符是否成对。
- **打开 SimonSays 时任务栏不再自动隐藏**：这是有意为之。SimonSays 位于任务栏上，所以它运行时会让任务栏保持可见，并在你退出时重新开启“自动隐藏任务栏”。如果 SimonSays 意外关闭（例如停电），则会在你下次退出 SimonSays 时重新开启该选项。
- **小组件按钮遮住了 SimonSays 栏**（Windows 11）：在 Windows **设置 → 个性化 → 任务栏**中关闭小组件。SimonSays 第一次发现小组件时，会提出打开该页面一次。
- **类别窗口太小或太大**：双击空白区域或窗口边缘以适应内容，或用 `F11` / `F12` 缩放。
- **我的类别或短语不见了**：检查设置（`F2`）中的语言；每种语言都有自己的板面。如果导入替换了你的板面，请参见[撤销更改](#撤销更改)。
- **“SimonSays 无法保存你的分类和短语”**：你的更改仍然显示，但关闭 SimonSays 后可能会丢失。请立即用 `F10` 导出你的板面以保留副本；如果反复出现，请告诉我们。该消息只出现一次，而不是每次编辑都出现，以免妨碍使用板面。
- **导入或导出错误**：检查文件权限和磁盘位置；然后重试。
- **语言或语音的更改没有生效**：重新打开设置并确认选择。如果更改仍未生效，请重新启动 SimonSays 后再试。
- **报告眼动仪问题**：如果支持人员要求提供诊断信息，请打开视线 / 注视点击窗口（`F3`）并点击 `保存诊断报告...`。报告（`hid_dump.txt`）会保存到 `%LocalAppData%\SimonSays\debug\`，并打开该文件夹。只有在你要求时才会创建。
