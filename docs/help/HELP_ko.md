# SimonSays 도움말 가이드

## 개요
SimonSays는 Juan Rey Saura가 만든 Windows용 텍스트 음성 변환(TTS) 도우미입니다. 처음에는 ALS(루게릭병) 환자와 더 이상 말을 할 수 없는 사람들이 컴퓨터에서 하던 일을 멈추지 않고 빠르게 대화할 수 있도록 만든 도구였습니다. 시간이 지나면서 같은 설계가 말하기가 어렵거나 불가능한 모든 사람을 위한 일반적인 AAC(보완대체의사소통) 도구로도 쓸모 있다는 것이 분명해졌습니다. 예를 들어 마비말장애, 후두 절제, 말실행증, 뇌졸중, 뇌 손상 때문에 말하기 어려운 경우입니다. 빠르게 말하기, 문구 모음, 텍스트 중간의 소리 재생에 맞게 최적화되어 있습니다. 여러 언어, 조정 가능한 음성, 효율적인 의사소통을 위한 기능을 지원합니다.

SimonSays는 Windows 작업 표시줄의 빈 공간을 사용하며, 몇 번의 클릭만으로 자주 쓰는(그리고 직접 바꿀 수 있는) 문구의 열두 개 정도 카테고리에 빠르게 접근할 수 있게 해 줍니다. 다른 창을 절대 가리지 않으므로 브라우저, 문서, 화상 통화에 머문 채 필요할 때 언제든 말할 수 있습니다. 키보드로, 마우스로, 또는 시선 추적기를 이용해 손을 쓰지 않고도 말할 수 있습니다.

사용 사례:
- 의사소통을 놓치지 않으면서 여러 Windows 앱을 집중적으로 사용할 때.
- 언어치료사가 말하기에 장애가 있는 사람을 위해 만드는 보드.
- [Virtual CABLE](https://vb-audio.com/Cable/)을 이용한 온라인 회의([온라인 회의에서 SimonSays 사용하기](#온라인-회의에서-simonsays-사용하기) 참조).

SimonSays는 Mind Express, TD Communicator, Grid 3, OptiKey 같은 완전한 의사소통 소프트웨어나, 그와 함께 보통 제공되는 전문적인 평가와 지원을 대신하려는 것이 아닙니다. 더 좁은 일을 합니다. 다른 앱에서 계속 작업하면서 작업 표시줄에서 빠르게 말하는 것입니다. 이런 프로그램과 함께 실행할 수도 있습니다. 예를 들어 OptiKey나 다른 시선 제어 소프트웨어로 커서를 움직이고, SimonSays가 문구를 말하게 할 수 있습니다.

SimonSays는 오픈 소스이고 무료이며(가격만이 아니라 자유라는 의미에서도 자유로운 소프트웨어입니다), 앞으로도 그럴 것입니다. 누구나 사용하고, 연구하고, 고치고, 나눌 수 있습니다. 광고가 없고 데이터를 수집하지 않습니다.

SimonSays는 버전 1.0에 가까워지고 있습니다. 그 전에, 자신의 음성, 보드, 시선 추적기로 일상에서 직접 써 볼 사람들이 필요합니다. 잘 안 되거나, 불편하거나, 빠진 것이 있으면 알려 주세요([의견, 지원 및 개인정보 보호](#의견-지원-및-개인정보-보호) 참조). 모든 의견이 도움이 됩니다.

## 시작하기
1. SimonSays를 시작합니다. Windows 작업 표시줄의 빈 공간에 나타나고 알림 영역에 아이콘을 추가합니다. 작업 표시줄은 화면의 아래, 위, 왼쪽, 오른쪽 어디에 있어도 됩니다.
   - 작업 표시줄 아이콘이 가운데 정렬되어 있으면 SimonSays는 작업 표시줄의 맨 앞(왼쪽 끝, 또는 세로 작업 표시줄에서는 맨 위)에 놓입니다. 왼쪽 정렬이면 알림 영역 바로 앞에 놓입니다.
   - 작은(얇은) 작업 표시줄에서는 SimonSays 막대가 낮아지고, 글꼴이 작아지며, 빠른 액세스 버튼 두 개가 나란히 놓입니다. 화면 왼쪽이나 오른쪽의 작업 표시줄에서는 컨트롤이 위아래로 쌓입니다.
   - 카테고리 창은 작업 표시줄 옆에 열리며, `카테고리` 버튼의 화살표가 열리는 방향을 보여 줍니다.
   - SimonSays가 실행 중일 때 작업 표시줄을 옮기거나 크기를 바꾸면 몇 초 안에 따라갑니다.
2. 말하려면 다음 중 하나를 합니다.
   - 막대의 텍스트 상자를 클릭합니다(또는 시선을 머무릅니다). 작업 표시줄 옆에 더 큰 입력 상자가 열립니다. 텍스트를 입력하고 `Enter`를 누르면 말합니다. 상자가 닫히고 포커스가 `재생>`으로 옮겨지므로, `Space`를 누르면 다시 말합니다(또는 멈춥니다). `Esc`를 누르면 말하지 않고 상자를 닫고 사용하던 창으로 돌아갑니다. 텍스트는 막대에 남아 있어 `재생>`으로 다시 말할 수 있습니다.
   - 카테고리 창에서 저장된 문구를 하나 이상 클릭합니다.
3. 재생 중에는 버튼에 `>`가 표시됩니다. 다시 누르면 바로 멈춥니다.

![작업 표시줄 위의 SimonSays 막대](img/bar.png)

`카테고리` 버튼 옆의 작은 **빠른 액세스 버튼** 두 개로, 보통은 바로 가기 키나 알림 영역 메뉴로 하는 두 가지 일을 한 번의 클릭으로 할 수 있습니다.

- 📂는 컴퓨터에 저장된 보드를 엽니다. `F9`와 같은 가져오기이지만, 내보내거나 다운로드한 보드가 보관되는 보드 폴더(`%LocalAppData%\SimonSays\boards\`)에서 시작합니다([카테고리 가져오기 및 내보내기](#카테고리-가져오기-및-내보내기) 참조).
- ⚙️는 `F2`와 같이 설정을 엽니다.

설정(`F2`)의 `빠른 액세스 버튼 및 메뉴 표시`로 둘 다 숨길 수 있으며, 그러면 입력 상자에 공간이 더 생깁니다. 같은 설정은 카테고리 창의 오른쪽 클릭 메뉴도 끕니다.

SimonSays가 숨겨져 있으면 알림 영역의 아이콘을 클릭해 다시 표시합니다.

## 카테고리 창
![기본 문구가 표시된 카테고리 창](img/categories.png)

- `카테고리` 버튼으로 엽니다. 크기를 바꿀 수 있으며, 크기를 유지하려면 설정에서 `카테고리 창 크기 기억`을 켭니다.
- 위쪽 목록에서 카테고리를, 아래쪽 목록에서 문구를 선택합니다.
- `선택 시 문장을 바로 말하기`가 켜져 있으면 문구를 한 번 클릭할 때 자동으로 말합니다. 꺼져 있으면 문구가 말하지 않고 기본 입력 상자에 들어갑니다.
- 빈 곳이나 창 가장자리를 두 번 클릭하면 모든 카테고리와 문구가 들어가도록 창 크기를 맞춥니다.
- 창의 빈 곳을 끌면 창이 이동하고, `Esc`를 누르면 숨겨집니다.
- `F12`와 `F11`로 확대와 축소를 합니다([바로 가기 키](#바로-가기-키) 참조).
- 버튼이나 빈 곳을 마우스 오른쪽 단추로 클릭하면(또는 `Shift + F10`이나 메뉴 키를 누르면) `붙여넣기`, `축소`, `확대`, `확대/축소 초기화`, `도움말`, `설정`, `시선 / 응시 클릭...`, `숨기기`, `SimonSays 종료...`가 있는 메뉴가 열리며, 각 항목에 바로 가기 키가 표시됩니다. 첫 번째 항목은 보드 제목(제목이 없으면 `제목 없는 보드`)을 보여 주며, 이 항목을 고르면 보드의 제작자 정보, 언어, 카테고리와 문구의 개수를 볼 수 있습니다. 이 메뉴는 설정에서 `빠른 액세스 버튼 및 메뉴 표시`가 켜져 있을 때만 나타납니다.
- 카테고리나 문구 버튼 위에서는 먼저 선택하지 않아도 그 버튼에 대해 `편집...`, `왼쪽으로 이동`, `오른쪽으로 이동`, `새 카테고리 추가...` 또는 `새 문구 추가...`, `카테고리 삭제...` 또는 `문구 삭제...`도 쓸 수 있습니다. 카테고리 위에서는 `카테고리 내보내기...`가 그 카테고리만 저장할지 보드 전체를 저장할지 묻습니다. 바로 가기 키 `F4`~`F8`은 그 버튼이 현재 선택일 때 표시됩니다. 이 키들은 선택한 항목에 작용하기 때문입니다. 빈 곳에서는 끝에 카테고리를 하나 추가하는 `새 카테고리 추가...`가 나타납니다. 빈 보드를 시작할 때도 이것을 씁니다.
- 카테고리와 문구 사이의 띠에는 주요 바로 가기 키 안내(보드에 캡션이 있으면 캡션)가 표시됩니다.

![문구 버튼의 오른쪽 클릭 메뉴](img/menu.png)

## 기본 문구
SimonSays에는 18개 언어마다 바로 쓸 수 있는 카테고리와 문구 세트가 들어 있으며, 가장 많이 필요한 문구일수록 적은 선택으로 닿도록 배열되어 있습니다.

- 👋🏻 자주 하는 인사
- 🗣️ 대화 문장
- 🚨 긴급 상황
- 🤲 돌봄과 편안함
- 🏥 건강
- 🏠 가족과 집
- 👥 사회
- ⏰ 시간과 날짜
- 💼 비즈니스
- ✈️ 여행
- 🔊 소리

언어마다 카테고리와 문구가 따로 있습니다. 설정(`F2`)에서 언어를 바꾸면 카테고리 창이 그 언어의 보드로 바뀌며, 한 언어에서 바꾼 내용은 다른 언어에 영향을 주지 않습니다.

문구는 Windows에 설치된 음성으로 말합니다. 사용하는 언어의 음성이 설치되어 있지 않아도 문구는 표시되지만, 다른 음성으로 말할 수 있습니다([문제 해결](#문제-해결) 참조).

기본 문구는 바꿀 수 있고 나중에 되돌릴 수도 있습니다. [카테고리와 문구 편집](#카테고리와-문구-편집)과 [기본 문구 복원](#기본-문구-복원)을 참조하세요.

## 바로 가기 키
- `F1`: 도움말 열기
- `F2`: 설정 열기
- `F3`: 시선 / 응시 클릭 설정
- `Enter`: 입력 상자의 텍스트 말하기
- `Esc`: 카테고리 창 숨기기
- `F11` / `Ctrl -`: 축소(카테고리 창)
- `F12` / `Ctrl +`: 확대(카테고리 창)
- `Ctrl + 0`: 확대/축소 초기화
- `Shift + F10` 또는 메뉴 키: 카테고리 창의 메뉴 열기(오른쪽 클릭과 같음)
- `재생>`에서 `Space`: 텍스트를 다시 말하거나, 재생 중에 멈추기

카테고리, 문구, 보드를 편집하는 바로 가기 키는 [카테고리와 문구 편집](#카테고리와-문구-편집)에 있습니다.

## 설정 (F2)
설정(`F2`)을 열면 다음을 조정할 수 있습니다. 설정은 두 열로 되어 있습니다.

![설정 창](img/settings.png)

**왼쪽 열**
- **기본 텍스트**: `기본 텍스트 자동 삽입`을 켜거나 끄고, 기본 문구를 바꿉니다.
  - `터치 키보드 표시`: 입력 상자가 열릴 때 화면 터치 키보드를 엽니다. 터치 키보드는 입력 상자 옆, 작업 표시줄에서 먼 쪽에 놓입니다.
- `빠른 액세스 버튼 및 메뉴 표시`: 기본 창의 `카테고리` 버튼 옆에 📂(보드 열기)와 ⚙️(설정) 버튼을 표시하고([시작하기](#시작하기) 참조), 카테고리 창의 오른쪽 클릭 메뉴도 켭니다([카테고리 창](#카테고리-창) 참조). 끄면 모두 숨겨지고 입력 상자에 공간이 더 생깁니다.
- **카테고리 창**:
  - 선택한 뒤 `카테고리 창 자동 최소화`.
  - `카테고리 창 크기 기억`.
  - `카테고리 창 크기를 내용에 맞게 자동 조정`: 카테고리와 문구를 불러올 때마다 카테고리 창을 그에 맞춥니다. 예를 들어 시작할 때, 언어를 바꾼 뒤, 가져오기를 한 뒤입니다.
- `시선 / 응시 클릭...`: 설정 위에 [시선 / 응시 클릭](#시선--응시-클릭-f3) 설정을 엽니다. 설정 창은 변경 내용을 유지한 채 열려 있습니다. 그곳에서 바꾼 내용은 그 창에서 `확인`을 누를 때 저장되며, 나중에 설정에서 `취소`를 눌러도 그대로 저장됩니다.

**오른쪽 열**
- **언어**: 인터페이스 언어를 고릅니다(English, Español, العربية, Euskara, Català, 简体中文, Français, Galego, Deutsch, עברית, हिन्दी, Italiano, 日本語, 한국어, Português, Português (Brasil), Русский, Valencià). 언어마다 카테고리와 문구도 따로 있습니다([기본 문구](#기본-문구) 참조).
- **음성**: 사용하는 언어에 맞는, 설치된 SAPI 음성을 고릅니다.
- **볼륨/속도**: `볼륨 (10-100)`과 `속도 (-10~10)`을 조정합니다.
- `음성 테스트`: 고른 음성을 들어 봅니다(`소리 출력`에서 고른 장치로 재생).
- `소리 출력`: SimonSays가 음성과 소리를 재생하는 곳입니다. `Windows 기본값`(보통의 선택) 또는 연결된 아무 장치나 고를 수 있습니다. 가상 오디오 케이블이 맨 앞에 나오며, [온라인 회의](#온라인-회의에서-simonsays-사용하기)에 필요한 것이 바로 이것입니다. 고른 장치가 연결되어 있지 않으면 SimonSays는 Windows 기본 장치로 재생하고 한 번 알려 줍니다. 선택은 유지되어 `(연결 안 됨)`으로 표시되며, 장치가 다시 연결되면 바로 다시 사용됩니다.
- `수신 대기 설정...`: Windows 녹음 장치를 엽니다. 여기서 가상 케이블에 대해 **이 장치로 듣기**를 켤 수 있습니다([온라인 회의에서 SimonSays 사용하기](#온라인-회의에서-simonsays-사용하기) 참조).
- **재생 동작**:
  - `선택 시 문장을 바로 말하기`(한 번 클릭으로 자동으로 말하기).
  - `이전 재생 중지`: 새 문구를 시작하기 전에 진행 중인 재생을 자동으로 멈춥니다.
  - `재생 중 SimonSays 볼륨 증가`: 말하는 동안 SimonSays가 재생에 쓰는 장치(`소리 출력` 참조)의 볼륨을 높이고, 끝나면 이전 수준으로 되돌립니다.
  - `재생 중 다른 오디오 임시 감소`: 말하는 동안 다른 앱의 볼륨을 낮추고, 끝나면 되돌립니다.

**아래쪽**
- `도움말`(왼쪽 아래 모서리, 또는 설정이 열려 있을 때 `F1`)은 `언어` 목록에서 고른 언어로 이 도움말을 엽니다. 설정은 변경 내용을 유지한 채 열려 있습니다.
- `확인`은 변경 내용을 저장하고, `취소`는 버립니다.

기본적으로 `선택 시 문장을 바로 말하기`, `카테고리 창 자동 최소화`, `카테고리 창 크기를 내용에 맞게 자동 조정`, `재생 중 SimonSays 볼륨 증가`, `재생 중 다른 오디오 임시 감소`는 켜져 있고, `이전 재생 중지`는 꺼져 있습니다.

## 시선 / 응시 클릭 (F3)
문구와 버튼에 시선(또는 마우스 커서)을 정해진 시간 동안 머무르면 손을 쓰지 않고 누를 수 있습니다. 새로운 기능이라 테스트와 의견이 필요합니다. 사용하는 트래커에서 어떻게 동작하는지 알림 영역 메뉴의 `의견 보내기`로 알려 주세요.

지원하는 구성:
- **마우스 커서를 움직이는 모든 시선 제어 소프트웨어**(Irisbond EasyClick, Tobii Dynavox Computer Control, Windows 시선 제어의 커서 모드, OptiKey): 응시 클릭이 커서를 따라갑니다.
- **시선을 직접 읽는 방식(커서를 움직일 필요 없음)**: Irisbond Hiru(HID 모드)와 자체 소프트웨어를 통한 Tobii 트래커. Tobii Eye Tracker 4C, Tobii Eye Tracker 5, Tobii Dynavox PCEye 5에서 확인했습니다.
- **Tobii Eye Tracker 5**: 현재 소프트웨어가 64비트 엔진만 설치하므로, SimonSays는 옆에 설치되는 작은 도우미 프로그램 `SimonSaysGaze64.exe`를 통해 읽습니다. 도우미는 필요할 때만 시작되고, 창이 없으며, SimonSays와 함께 닫히고, 시선 데이터를 컴퓨터 밖으로 내보내지 않습니다. 저장되거나 어디로 보내지는 일은 없습니다.
- **Tobii Eye Tracker 4C 및 Eye Tracker 5 라이선스**: 이 트래커에 대한 Tobii의 최종 사용자 라이선스는 병원이나 기타 의료 환경에서의 사용을 포함해 의료 목적의 사용을 허용하지 않습니다. PCEye 5 같은 Tobii Dynavox 기기에는 각각의 라이선스 조건이 있습니다.
- **Tobii Eye Tracker 4C 소프트웨어**: SimonSays는 Tobii Core를 통해 4C를 읽습니다. 같은 컴퓨터에 Eye Tracker 5를 연결하면 Windows가 Tobii Experience를 설치하는데, 이 프로그램이 Tobii Core를 끄기 때문에 4C가 작동하지 않게 됩니다. 4C를 다시 쓰려면 Tobii Core를 다시 설치하세요. 권장 버전은 `Tobii_Eye_Tracking_Core_v2.13.1.7294_x86.exe`이며 [Tobii 시작 페이지](https://gaming.tobii.com/getstarted/)에서 받을 수 있습니다.

응시 클릭이 동작하는 곳:
- SimonSays 막대, 카테고리 창과 그 안의 문구 및 카테고리 버튼.
- SimonSays 자체 창과 질문의 버튼: 설정, 시선 / 응시 클릭 창, 추가·편집·미리 보기 대화 상자, 그리고 `예` / `아니요`나 `확인` / `취소` 같은 모든 확인 창. 이 버튼들은 사용하는 언어로 표시되며, 창이 열린 뒤 약 0.75초가 지나야 응시에 반응하기 시작합니다. 보고 있던 자리에 나타난 질문이 저절로 답해지지 않게 하기 위해서입니다.
- 시선을 직접 읽을 때는 보고 있는 버튼이 마우스를 올렸을 때처럼 밝아지므로, 진행이 시작되기 전에 무엇을 고르려는지 알 수 있습니다. 눈을 깜빡여도 강조 표시는 유지되고, 시선을 돌리면 사라집니다.

![시선 / 응시 클릭 창](img/dwell.png)

시선 / 응시 클릭 설정(`F3`, 알림 영역 메뉴, 또는 설정의 `시선 / 응시 클릭...` 버튼)을 열면 다음을 설정할 수 있습니다.
- **활성화 모드**: 다음 중 하나를 고릅니다.
  - `자동`: 연결된 장치를 감지하고, 상황에 따라 마우스 커서나 시선 감지로 응시 클릭을 켭니다. 백그라운드에서 실행되는 Tobii 소프트웨어(설치 후 항상 실행)만으로는 커서 응시가 켜지지 않습니다. Tobii 트래커는 실제로 시선을 추적하고 있을 때만 사용됩니다.
  - `마우스 커서`: 항상 마우스 커서로 응시 클릭을 켭니다.
  - `HID 시선 추적기`: 항상 시선 감지로 응시 클릭을 켭니다(HID 모드의 Irisbond Hiru 또는 Tobii 트래커). 버튼을 누르는 것은 시선뿐입니다. 시선 데이터가 들어오지 않는 동안(추적이 꺼져 있거나 트래커가 분리된 경우)에는 응시로 아무것도 눌리지 않고, 마우스는 평소처럼 동작합니다.
  - `끄기`: 항상 응시 클릭을 끕니다.
  - **고정 인식 지연**: 진행 막대가 시작되기 전에 시선(또는 커서)이 버튼 위에 머물러야 하는 시간(밀리초, 기본값 150). 그래서 버튼 위를 시선이 지나가기만 할 때는 진행이 전혀 표시되지 않습니다. 버튼은 고정 인식 지연에 응시 시간을 더한 뒤에 눌립니다. 0으로 설정하면 진행이 바로 시작됩니다.
  - **응시 시간**: 요소를 바라볼 때 클릭이 일어나는 데 필요한 시간(밀리초, 기본값 500). 응시하는 동안 진행 표시가 나타납니다.
  - **허용 반경**: 시선의 허용 범위(픽셀)로, 눈이 조금 움직여도 응시가 끊기지 않게 합니다.
  - **쿨다운**: 누른 뒤 응시 클릭이 다시 일어나지 않는 시간(밀리초)으로, 실수로 여러 번 클릭되는 것을 막습니다.
  - **진행 색상**: 응시 진행 표시의 색상(기본값은 Windows 강조 색).
  - **응시로 다시 누르기 전에 벗어나기**(기본적으로 켜짐): 응시 클릭 뒤에는 포인터나 시선이 그 자리에서 벗어나거나(허용 반경 밖으로) 잠깐 다른 곳을 볼 때까지 어떤 버튼도 응시로 다시 눌리지 않습니다. 버튼 위에 머물러 있어도 한 번만 눌리므로, 긴 문구가 끝나기 전에 반복되지 않습니다. 마우스 클릭에는 영향이 없습니다.
  - **트래커 사용 방식 감지**: 시선 추적기로 마우스 커서를 움직이는지, 그냥 버튼을 클릭하는지를 앱이 알아내도록 돕는 버튼 두 개.
  - **감지됨**: 감지된 장치 종류와 관련 소프트웨어에 대한 자세한 정보를 보여 줍니다.
  - `진단 보고서 저장...`(감지됨 아래): 시선 추적기와 그 소프트웨어에 대한 보고서를 `hid_dump.txt`에 쓰고 그 폴더를 열어, 지원팀에 보낼 수 있게 합니다.
  - `초기화` 버튼(왼쪽 아래)은 모든 응시 설정을 기본값으로 되돌립니다.
  - `확인` 버튼은 변경 내용을 저장하고, `취소`는 버립니다.

## 온라인 회의에서 SimonSays 사용하기
SimonSays는 화상 통화(Teams, Zoom, Google Meet…)에서 직접 말할 수 있어, 다른 참가자들은 내 문구를 마이크에서 나오는 소리처럼 듣게 됩니다. 이렇게 하려면 무료 [VB-Audio Virtual Cable](https://vb-audio.com/Cable/) 같은 가상 오디오 케이블이 필요합니다.

1. 가상 오디오 케이블을 설치하고, 요청하면 Windows를 다시 시작합니다.
2. SimonSays의 소리를 케이블로 보냅니다. 설정(`F2`)을 열고 `소리 출력`에서 `CABLE Input`을 고릅니다(가상 케이블이 맨 앞에 나옵니다). `음성 테스트`를 눌러 확인합니다. 소리가 이제 케이블로 가므로 스피커에서는 들리지 않아야 합니다.
3. 회의 앱에서 마이크로 `CABLE Output`을 고릅니다.
4. 나도 SimonSays를 들으려면 설정에서 `수신 대기 설정...`을 누릅니다. Windows 녹음 장치가 열리면 `CABLE Output`을 고르고, **속성 → 수신 대기**를 열어 **이 장치로 듣기**를 선택하고, **이 장치를 통해 재생**에서 스피커나 헤드셋을 고른 다음 `확인`을 누릅니다. 이 작업은 한 번만 하면 됩니다.

SimonSays가 대신 **이 장치로 듣기**를 켤 수는 없습니다. 이것은 케이블의 녹음 쪽 설정이고 Windows는 사용자 본인만 바꿀 수 있게 하므로, `수신 대기 설정...`이 알맞은 창을 바로 열어 줍니다.

알아 두면 좋은 점:
- Windows 기본 재생 장치는 `CABLE Input`이 아니라 스피커나 헤드셋으로 두세요. **이 장치로 듣기**의 재생 대상이 "기본 재생 장치"인데 그 기본 장치가 케이블이면, 소리가 다시 케이블로 들어가 반복됩니다.
- 회의에서 문구는 들리는데 효과음(박수, 초인종)이 들리지 않으면, 회의 앱의 소음 억제가 그 소리를 지우고 있는 것입니다. 앱에서 소음 억제를 줄이거나 끄세요.
- 케이블을 제거하거나 연결이 끊기면 SimonSays는 Windows 기본 장치로 재생하고 한 번 알려 줍니다. 케이블을 다시 쓸 수 있게 되면 바로 케이블로 돌아갑니다.
- 통화용 문구를 준비하려면 **회의 템플릿** 카테고리를 추가하세요. `F9`나 📂 버튼을 누르고 내 언어로 된 이름의 보드를 엽니다(한국어는 `SimonSays_회의_템플릿_(한국어).ssc`). 인사, "제 말 들리세요?", 프로그램으로 말한다는 짧은 설명, 예 / 아니요, 동의 / 반대, 다시 말해 달라거나 천천히 말해 달라는 부탁, 작별 인사가 들어 있습니다. 내 회의에 맞는 문구를 추가하도록 편집하세요.
- 2단계 대신 Windows의 앱별 설정(**설정 → 시스템 → 소리 → 볼륨 믹서**)으로 SimonSays의 출력을 바꾸고, `소리 출력`은 `Windows 기본값`으로 둘 수도 있습니다. SimonSays는 무언가를 재생한 뒤에야 이 목록에 나타납니다.

## 알림 영역 아이콘 메뉴
- `표시` / `숨기기`: 기본 화면을 표시하거나 숨깁니다
- `설정`
- `시선 / 응시 클릭...`
- `웹`: SimonSays 웹 페이지를 엽니다
- `정보`: 버전과 제작자 정보를 표시합니다
- `의견 보내기`: 기본 브라우저에서 [의견 양식](https://forms.gle/KMbpEDYmwnFJUhgy8)을 엽니다
- `종료`: 먼저 확인한 뒤 SimonSays를 종료합니다

알림 영역의 팝업 창과 다른 대화 상자는 제목 표시줄을 끌어 옮길 수 있습니다. 카테고리 창은 가장자리를 끌어 크기를 바꿀 수 있으며, 설정에서 `카테고리 창 크기 기억`을 켜면 크기가 유지됩니다.

## 카테고리와 문구 편집
이 섹션과 이후 섹션은 보드의 카테고리, 문구, 소리, 모양을 바꾸는 보호자, 언어치료사, 고급 사용자를 위한 것입니다. 모든 변경은 바로 저장됩니다([변경 내용 되돌리기](#변경-내용-되돌리기) 참조).

### 어떤 편집기를 사용할까
- **SimonSays에서**: 일상적인 변경. 카테고리와 문구의 이름 바꾸기, 추가, 이동, 삭제, 이모지 넣기, 소리 추가, 문구 목록 붙여넣기, 색 조정 등입니다. 이 섹션의 나머지 부분에서 방법을 설명합니다.
- **[SimonSays Web](https://github.com/juan-rey/simonsays-web)에서**: 더 큰 보드 작업으로, 여기서 하는 편이 훨씬 쉽습니다. AAC 그림 상징으로 만든 보드(ARASAAC 그림 상징 라이브러리를 검색할 수 있습니다), 직접 만든 아이콘 이미지, 색·크기·배치를 정한 스타일 보드 등입니다. 단어 묶음마다 색이 다른 **Fitzgerald Key** 보드를 만들 때 특히 권장합니다. `.ssc`/`.ssz` 보드를 업로드하지 않고 브라우저 안에서 바로 열고 저장하는 시각적 편집기입니다. 작업이 끝나면 `F9`나 📂 버튼으로 SimonSays에 보드를 가져옵니다. SimonSays 보드를 다른 플랫폼에서 쓰는 방법이기도 합니다.

편집용 바로 가기 키(카테고리 창):
- `F4`: 현재 선택 편집
- `F5` / `F6`: 목록에서 이전 / 다음 항목으로 이동
- `F7`: 현재 선택 뒤에 추가(상황에 따라 카테고리 또는 문구)
- `F8`: 현재 선택 삭제
- `F9`: 카테고리 가져오기
- `F10`: 카테고리 내보내기
- `Ctrl + F4`: 보드 스타일 편집([모양 사용자 지정](#모양-사용자-지정-보드-및-카테고리-스타일) 참조)
- `Ctrl + F8`: 모든 카테고리와 그 문구 삭제(두 번 확인함)
- `Ctrl + V` 또는 `Shift + Insert`: 복사한 텍스트를 단락마다 하나씩 문구로 추가([문구 관리](#문구-관리) 참조)
- `.txt`, `.ssc`, `.ssz` 파일을 창으로 끌기: `.txt`는 새 카테고리로 추가하고, 보드는 `F9`처럼 가져옵니다([카테고리 관리](#카테고리-관리) 참조)

> **팁:** `Ctrl + F8`을 쓰거나 보드 전체를 가져오기(`F9`) 전에 보드를 내보내 두면(`F10`) 되돌릴 수 있습니다.

### 카테고리 관리
- 이름 바꾸기: 카테고리 선택 → (바로 가기 키: `F4`) `카테고리 이름 변경` → 이름 바꾸기 → `확인`.
- 선택 이동: 목록을 살펴볼 때 `F5`/`F6`으로 이전/다음 항목으로 이동합니다.
- 추가: 카테고리 선택 → (바로 가기 키: `F7`) `새 카테고리 추가` 대화 상자 → 이름 입력 → `확인`.
- 삭제: 카테고리 선택 → (바로 가기 키: `F8`) `카테고리 삭제` → 카테고리와 그 문구를 삭제할지 확인합니다.
- 텍스트 파일에서 추가: `.txt` 파일을 카테고리 창으로 끌어 놓기 → 파일 이름으로 된 카테고리가 만들어지고 단락마다 문구가 하나씩 들어갑니다(단락은 빈 줄로 구분) → 미리 보기 확인 → `확인`. 여러 파일을 한꺼번에 놓을 수 있으며, 각각 미리 보기가 따로 나옵니다. 이름이 기존 카테고리와 같은 파일은 받아들여지지 않습니다.
- 끌어서 보드 열기: `.ssc`나 `.ssz` 파일을 카테고리 창으로 끌어 놓기 → SimonSays가 가져올지 묻고, `예`를 고르면 `F9`와 같이 가져옵니다([카테고리 가져오기 및 내보내기](#카테고리-가져오기-및-내보내기) 참조). 파일에 보드 전체가 들어 있으면 현재 보드를 대체하며, 그 전에 현재 보드의 사본이 `backup.ssz`로 저장됩니다. 텍스트 파일과 보드 파일을 함께 놓을 수 있으며, 하나씩 차례로 처리됩니다. 파일 탐색기에서 `.ssc`나 `.ssz` 파일을 열어도(두 번 클릭) 같은 질문을 합니다.

#### 카테고리 아이콘 설정 또는 변경
카테고리 버튼에는 이모지나 직접 고른 이미지 파일(`.ico`, `.png`, `.jpg`)을 표시할 수 있습니다. 추가·편집 대화 상자에서 구분 접두사 `##`로 아이콘을 지정합니다.

```
<아이콘>##<카테고리 이름>
```

- **이모지**: 이모지(하나 이상) 뒤에 `##`와 이름을 입력합니다.
  - 예: `🙂##인사`
- **아이콘 파일**(`.ico`, `.png`, `.jpg`): 파일 이름이나 전체 경로 뒤에 `##`와 이름을 입력합니다. 폴더가 없는 파일 이름은 [소리 및 아이콘 파일 검색 순서](#소리-및-아이콘-파일-검색-순서)에 설명된 대로 찾습니다.
  - 예: `C:\icons\smile.png##인사`
- **아이콘 없음**: `##` 없이 카테고리 이름만 입력합니다.
  - 예: `인사`

> 참고: 파일 아이콘으로는 `.ico`, `.png`, `.jpg` 파일만 지원합니다. 다른 확장자는 무시되고 아이콘이 표시되지 않습니다. PNG 이미지는 투명도가 유지되며, 아주 큰 이미지는 불러올 때 자동으로 줄어듭니다.

### 문구 관리
- 편집: 문구 선택 → (바로 가기 키: `F4`) `문구 편집` → 텍스트 수정 → `확인`.
- 선택 이동: `F5`/`F6`으로 이전/다음 문구로 이동합니다.
- 추가: 문구 선택 → (바로 가기 키: `F7`) `새 문구 추가` → 텍스트 입력 → `확인`.
- 삭제: 문구 선택 → (바로 가기 키: `F8`) `문구 삭제` → 확인합니다.
- 한꺼번에 여러 개 추가: 문구를 빈 줄로 구분한 텍스트 복사 → 문구(또는 카테고리) 선택 → `Ctrl + V` → 미리 보기 확인 → `확인`. 문구는 선택한 문구 뒤, 또는 카테고리 끝에 추가됩니다. 단락 안의 줄 바꿈은 공백이 되며, 아이콘 표시 `##`와 오디오 표시 `::`는 `새 문구 추가` 대화 상자에서와 같이 동작합니다.
- 소리 추가: `.wav`나 `.mp3` 파일을 하나 이상 카테고리 창으로 끌어 놓기 → 미리 보기 확인 → `확인`. 각 파일은 파일 이름으로 된 소리 문구가 되어 선택한 문구 뒤(또는 선택한 카테고리 끝)에 추가되고, 파일은 보드의 리소스 폴더에 복사되어 보드를 내보낼 때 함께 갑니다. 기존 파일은 절대 덮어쓰지 않습니다. 같은 이름의 다른 소리가 이미 있으면 새 파일은 `name (2).wav`로 저장됩니다.

#### 문구 아이콘 설정 또는 변경
문구도 카테고리와 같은 아이콘 접두사 규칙을 따르며, 문구 텍스트 앞에 생략할 수 있는 구분자 `##`를 둡니다.

```
<아이콘>##<문구 텍스트>
```

- **이모지**: `👍##좋아요!`
- **아이콘 파일**: `C:\icons\check.png##좋아요!`
- **아이콘 없음**: `좋아요!`

문구에는 오디오 파일을 넣을 수도 있습니다([음성과 소리 섞기](#음성과-소리-섞기) 참조). 아이콘, 텍스트, 오디오를 함께 쓰려면 다음 형식을 사용합니다.

```
<아이콘>##<문구 텍스트>::<오디오 파일>
```

- 예: `🔔##주목해 주세요::alert.mp3`

접두사 `##`와 접미사 `::`는 둘 다 생략할 수 있고 서로 독립적이므로, 어떤 조합이든 쓸 수 있습니다.
- 아이콘 접두사만: `🔔##주목해 주세요`
- 오디오 접미사만: `주목해 주세요::alert.mp3`
- 둘 다: `🔔##주목해 주세요::alert.mp3`
- 둘 다 없음: `주목해 주세요`

## 음성과 소리 섞기
- 구분 기호 `♫`를 사용해 텍스트 안에 오디오 파일 이름을 넣습니다.
  - 예: `안녕하세요 ♫doorbell.mp3♫ 잠시만 기다려 주세요.`
  - 구분 기호 밖의 텍스트는 말하고, 안의 텍스트는 소리 파일로 취급되어 그 자리에서 재생됩니다.
- 지원하는 오디오: `.wav`와 `.mp3`. MIDI 파일(`.mid`, `.midi`)은 문구에 쓸 수는 있지만 재생되지 않으니 `.wav`나 `.mp3`로 변환하세요.
- 프로그램이 접근할 수 있는 절대 경로나 상대 경로를 사용하세요. 구분 기호는 반드시 짝을 맞춰, 나머지 텍스트가 오디오로 취급되지 않게 하세요.
- `♫`를 입력하려면 이 도움말에서 복사하거나, 소리가 들어 있는 문구를 고르세요. 그 문구의 `♫…♫` 표시가 입력 상자에 들어가며, 그 앞뒤에 텍스트를 추가할 수 있습니다.

### SimonSays에 포함된 소리
이 소리들은 SimonSays와 함께 설치되며, 어떤 텍스트나 문구에서든 이름으로 쓸 수 있습니다. 예를 들어 입력 상자에서는 `♫laugh.mp3♫`, "잘했어요!"라고 표시되고 박수 소리를 내는 문구 버튼에는 `잘했어요!::applause.mp3`를 씁니다.

`ahem.mp3`, `alert.mp3`, `applause.mp3`, `aww.mp3`, `beep.mp3`, `boo.mp3`, `call_bell.mp3`, `censor.mp3`, `doorbell.mp3`, `drumroll.mp3`, `evil_laugh.mp3`, `fail.mp3`, `hmmmm.mp3`, `kisses.mp3`, `laugh.mp3`, `mmm-hmm.mp3`, `nuh-uh.mp3`, `phone_ring.mp3`, `rimshot.mp3`, `scream.mp3`, `shots.mp3`, `sigh.mp3`

### 소리 및 아이콘 파일 검색 순서
소리나 아이콘 파일 이름에 드라이브 문자나 전체 경로가 없으면, SimonSays는 다음 순서로 찾아 처음 찾은 파일을 사용합니다.

1. **현재 보드의 리소스 하위 폴더**: 보드 스타일에 `title`이나 `resource-folder`가 설정되어 있으면, 리소스 폴더 안에 있는 그 보드 전용 하위 폴더([모양 사용자 지정](#모양-사용자-지정-보드-및-카테고리-스타일) 참조).
2. **리소스 폴더**: `%LocalAppData%\SimonSays\resources\`(보드 아이콘과 소리의 기본 위치이며, 가져온 `.ssz` 패키지가 파일을 여기에 설치합니다).
3. **SimonSays 데이터 폴더**: `%LocalAppData%\SimonSays\`(리소스 폴더가 생기기 전에 이전 버전이 여기에 둔 파일을 위해 남겨 둔 예비 위치).
4. **작업 디렉터리**: 프로세스의 현재 작업 디렉터리(프로그램 폴더와 다를 때만 찾습니다).
5. **프로그램 폴더**: `SimonSays.exe`가 있는 폴더.

이 위치 어디에서도 파일을 찾지 못하면 내장된 대체 소리를 사용합니다(아이콘은 그냥 표시되지 않습니다).

> **팁:** 직접 준비한 소리와 아이콘 파일은 `%LocalAppData%\SimonSays\resources\`에 두는 것을 권장합니다. 앱을 업데이트해도 남아 있고 사용자별로 따로 관리됩니다. `title`이나 `resource-folder` 스타일이 있는 보드는 그곳에 자동으로 전용 하위 폴더가 생겨, 다른 보드의 파일과 분리됩니다.

## 모양 사용자 지정 (보드 및 카테고리 스타일)
카테고리 창과 그 버튼의 색, 크기, 스타일을 바꿀 수 있습니다. 예를 들어 Fitzgerald Key 같은 색으로 구분한 의사소통 보드를 만들 때 씁니다. 스타일은 선택 사항이며, 스타일이 없으면 창은 기본 모양을 유지합니다.

> **팁:** 아래 내용은 모두 SimonSays에서 입력할 수 있어 작은 조정에 편리합니다. 스타일을 적용한 보드나 그림 상징 보드를 통째로 디자인하려면 [SimonSays Web](https://github.com/juan-rey/simonsays-web)을 권장합니다. 작업하면서 결과를 볼 수 있고, 이 스타일을 대신 작성해 줍니다([어떤 편집기를 사용할까](#어떤-편집기를-사용할까) 참조).

스타일은 `property:value;` 쌍의 목록입니다. 값으로는 다음을 쓸 수 있습니다.
- **색**: 16진수 `#RRGGBB`. 예: `#FFD966`.
- **크기**: 픽셀 수(`96`) 또는 기본값에 대한 백분율(`120%`).
- **키워드**: 예: `left`, `right`, `top`, `bottom`, `smart`, `normal`, `bold`.
- **텍스트**: 글꼴 이름, 또는 캡션·제목·제작자 정보의 텍스트.

앱이 알아보지 못하는 것(철자가 틀린 속성이나 잘못된 값)은 그냥 무시되므로, 스타일 때문에 창이 망가지는 일은 없습니다.

### 카테고리 하나의 스타일 (편집 창)
카테고리를 고르고 `F4`(편집)를 누른 다음, 이름 뒤에 `::`와 스타일을 덧붙입니다.

```
<아이콘>##<카테고리 이름>::<property>:<value>;<property>:<value>;
```

- 예: `🧍##사람::background:#FFD966;`는 사람 버튼을 노란색으로 칠합니다. 카테고리의 색은 **그 안의 문구에도 적용**되므로 한 줄로 단어 묶음 전체에 색이 입혀집니다. 이것이 Fitzgerald Key 보드의 핵심입니다.
- 카테고리 스타일에서는 카테고리 버튼의 `background`와 `text-color`를 정할 수 있고, 문구 속성(아래 참조)에 `phrase-` 접두사를 붙여 정할 수도 있습니다. 예: `phrase-corner-radius:8;`.

### 보드 전체의 스타일 (`$$board`)
전체 모양(창 배경, 구분선, 모든 카테고리 버튼과 문구 버튼의 기본값)은 **보드 스타일**입니다. 예약된 카테고리 이름 `$$board`로 저장됩니다(내 카테고리에는 `$$`로 시작하는 이름을 쓸 수 없습니다).

- 카테고리 창에서 `Ctrl + F4`를 눌러 **편집**합니다. 편집기에는 한 줄에 하나씩 `property:value;`가 표시됩니다. `확인`으로 확정하면 새 스타일이 적용되고, SimonSays가 "변경 내용을 되돌릴까요?"라고 묻습니다. 이전 스타일로 돌아가려면 `확인`을, 새 스타일을 유지하려면 `취소`를 고릅니다.
- 스타일이 있는 카테고리 파일(`.ssc` / `.ssz`)을 가져와 **스타일을 얻을** 수도 있습니다. 보드 스타일이 들어 있는 파일을 가져오면, SimonSays는 지금 스타일을 바꾸기 전에 묻고, 가져오기 메시지에 보드의 `title`과 `credits`(있으면)를 보여 줍니다. 보드 스타일이 `title`, `credits`, `language`, `resource-folder`만 정하는 파일은 눈에 보이는 것을 바꾸지 않으므로 SimonSays는 묻지 않습니다. 카테고리가 하나만 들어 있으면 그 카테고리가 추가되고 모양은 그대로이며, 보드 전체가 들어 있으면 다른 보드 전체와 마찬가지로 모양까지 포함해 보드를 대체합니다.

### 스타일 속성
- **창 전체**: `background`, `separator-color`, `text-color`, `font-name`, `font-size`, `text-weight`, `caption`(구분선 사이에 표시되는 캡션), `title`과 `credits`(보드를 가져올 때 표시), `language`(보드를 만든 대상 언어. 예: `language:Korean`. 설정된 언어가 다르면 SimonSays는 보드 가져오기를 거부하고, 설정(`F2`)에서 어떤 언어로 바꿔야 하는지 알려 줍니다).
- **모든 카테고리 버튼**(`category-` 접두사)과 **모든 문구 버튼**(`phrase-` 접두사): `background`, `text-color`, `width`, `height`, `corner-radius`, `border-width`, `margin`, `icon-position`(`left`/`right`/`top`/`bottom`/`center`), `icon-size`, `font-name`, `font-size`, `text-weight`, `text-layout`.

`icon-position`을 `center`로 하면 아이콘이 버튼 가운데에 놓이고 텍스트는 숨겨집니다(아이콘만 있는 키). 아이콘을 위에, 이름을 그 아래에 두려면 `top`을 쓰세요. 가운데 아이콘 위에 텍스트도 보이게 하려면 `text-layout`을 명시하면(예: `text-layout:bottom`) 그 위치에 표시됩니다.

`text-layout`에는 가로(`left`/`center`/`right`) 키워드와/또는 세로(`top`/`middle`/`bottom`) 키워드, 또는 `smart`를 지정합니다. 기본값은 smart이며, 텍스트를 아이콘이 남긴 공간의 가운데에 둡니다(아이콘이 위 → 캡션은 아래 가운데, 아이콘이 없으면 버튼 전체의 가운데).

### 예: 색으로 구분한 Fitzgerald Key 보드
단어 묶음 여섯 개에 색을 입히려면, 각 카테고리를 편집해(`F4`) 배경색을 하나씩 지정합니다. 편집 대화 상자에 입력하는 정확한 문자열은 다음과 같습니다.

```
🧍##사람::background:#FFD966;
🏃##동작::background:#93C47D;
📏##꾸밈말::background:#6FABDC;
🍎##사물::background:#F6B26B;
🕒##기타::background:#FFFFFF;
👋##인사::background:#B4A7D6;
```

각 색은 그 카테고리의 문구에도 입혀지므로, 보드 전체가 색으로 구분됩니다. 보드 전체의 마무리(예: 각 카테고리의 이모지를 위에, 이름을 아래에 두고 구분선에 색 입히기)는 다음과 같은 보드 스타일(`Ctrl + F4`)로 합니다.

```
category-icon-position:top;separator-color:#B4A7D6;
```

모든 키에 그림 상징이 있고 문구가 단어 묶음별로 배열된 완전한 Fitzgerald Key 보드는 [SimonSays Web](https://github.com/juan-rey/simonsays-web)에서 만든 뒤 `F9`로 가져오세요.

스타일은 카테고리와 함께 움직입니다. 내보내기(`F10`)에 포함되고 가져오기(`F9`)로 함께 들어오므로, 스타일이 있는 보드를 파일 하나로 나눌 수 있습니다.

## 카테고리 가져오기 및 내보내기
보드는 `.ssc` 파일(카테고리와 문구) 또는 `.ssz` 파일(같은 내용에 사용하는 소리와 아이콘 파일을 더한 단일 파일)로 나눕니다. [SimonSays Web](https://github.com/juan-rey/simonsays-web)으로 브라우저에서 눈으로 보며 만들고 편집할 수도 있습니다.

- **내보내기**(`F10`): 물어보면 모든 카테고리를 내보낼지, 선택한 카테고리만 내보낼지 고릅니다. 저장 대화 상자는 기본적으로 `%LocalAppData%\SimonSays\boards\`에서 열리지만 어디에나 저장할 수 있습니다. 카테고리나 문구가 SimonSays가 찾을 수 있는 소리나 아이콘 파일을 쓰면 자동으로 `.ssz`로 저장합니다(`.mid`/`.midi` 소리는 포함되지 않습니다). 모든 카테고리를 내보내면 보드 스타일이 포함되고, 카테고리 하나를 내보내면 그 카테고리의 스타일만 포함됩니다. 성공이나 실패 메시지는 선택한 언어로 표시됩니다.
- **가져오기**(`F9`): `.ssc`나 `.ssz` 파일을 고릅니다.
  - **카테고리가 여러 개이거나 보드 스타일이 있는** 파일은 보드 전체입니다. **현재 언어의 모든 카테고리와 문구를 대체합니다**. 그 전에 이전 보드가 `backup.ssz`로 저장됩니다([변경 내용 되돌리기](#변경-내용-되돌리기) 참조).
  - **카테고리가 하나뿐인** 파일은 내 보드에 추가됩니다. 같은 이름의 카테고리가 이미 있으면 덮어쓸지 묻습니다. 파일이 보드 이름(`title`, `credits`, `language`)만 정하고 색·크기·글꼴이 없을 때도 마찬가지입니다. 이런 정보는 내 보드나 그 모양을 대체하지 않습니다.
  - `.ssz` 안의 소리와 아이콘 파일은 리소스 폴더에 설치되고, 카테고리 창은 가져온 보드에 맞게 크기가 바뀝니다. 성공이나 실패 메시지는 선택한 언어로 표시됩니다.

## 변경 내용 되돌리기
SimonSays는 모든 변경을 바로 저장하며, 일반적인 실행 취소 명령은 없습니다. 되돌리는 방법은 다음과 같습니다.

- **가져오기 되돌리기**: 가져오기로 보드가 대체되기 전에, SimonSays는 이전 보드를 `%LocalAppData%\SimonSays\boards\`에 `backup.ssz`로 저장합니다. 가져오기를 되돌리려면 `F9`를 누르고 `backup.ssz`를 고릅니다. 이전 보드가 카테고리와 모양 그대로, 더 묻지 않고 돌아옵니다. 가장 최근에 대체된 보드 하나만 보관되며, 보드 전체를 새로 가져올 때마다 백업을 덮어씁니다.
- **보드 스타일 변경 되돌리기**: `Ctrl + F4`로 보드 스타일을 편집한 뒤 SimonSays가 "변경 내용을 되돌릴까요?"라고 물으면, `확인`을 골라 이전 스타일로 돌아갑니다.
- **카테고리나 문구 변경 되돌리기**: `F4`, `F7`, `F8`로 한 변경은 자동으로 되돌릴 수 없습니다. 중요한 보드를 크게 바꾸기 전에 내보내 두세요(`F10`). 나중에 그 파일을 가져오면(`F9`) 그 시점으로 돌아갑니다.

### 기본 문구 복원
SimonSays는 내 카테고리와 문구를 절대 덮어쓰지 않으므로, 업데이트로 새로 생긴 기본 문구는 아직 쓰지 않은 언어에만 나타납니다. 내장된 카테고리와 문구로는 언제든 돌아갈 수 있습니다. 예를 들어 처음부터 다시 시작하거나 업데이트의 새 문구를 받고 싶을 때입니다. 이 작업은 **현재 언어의 보드 전체를 대체합니다**.

1. `카테고리` 옆의 📂 버튼을 클릭합니다(또는 카테고리 창에서 `F9`를 누릅니다). 보드 폴더가 열립니다.
2. 내 언어의 기본 문구 보드를 고릅니다. 한국어는 `SimonSays_기본_문구_(한국어).ssc`입니다(다른 언어도 그 언어로 같은 형식의 이름입니다. 예: `SimonSays_default_phrases_(English).ssc`).
3. 가져오기를 확인합니다. 그 전에 현재 보드가 `backup.ssz`로 저장되므로 나중에 되찾을 수 있습니다([변경 내용 되돌리기](#변경-내용-되돌리기) 참조).

이 보드에는 항상 실행 중인 SimonSays 버전의 기본 문구가 들어 있습니다. SimonSays는 시작할 때와 언어를 바꿀 때 보드 폴더에서 이 파일을 업데이트합니다. 내 보드를 남겨 두려면 먼저 원하는 이름으로 내보내세요(`F10`). `backup.ssz`는 다음 가져오기 때 덮어쓰입니다.

보드 폴더에 파일이 없으면 마지막 방법이 있습니다. SimonSays를 종료하고(알림 영역 메뉴 → `종료`), 레지스트리 편집기(`regedit`)를 열어 `HKEY_CURRENT_USER\SOFTWARE\SimonSays\Phrases\` 아래에서 내 언어의 영어 이름으로 된 키(예: `Korean`)를 삭제한 다음, SimonSays를 다시 시작합니다. 그 언어의 기본 카테고리와 문구가 백업 없이 새로 만들어집니다.

`Portuguese (Brazil)`의 경우: `Portuguese` 키도 있으면 SimonSays는 브라질 포르투갈어 기본 문구를 만드는 대신 그 보드를 `Portuguese (Brazil)`로 복사하므로, `Portuguese` 키도 삭제하세요(사용 중이라면 먼저 내보내세요).

## SimonSays가 파일을 저장하는 위치
- **카테고리, 문구, 설정**은 Windows 레지스트리의 `HKEY_CURRENT_USER\SOFTWARE\SimonSays`에 저장됩니다(언어별 보드는 `Phrases\<Language>` 아래).
- `%LocalAppData%\SimonSays\resources\`: 내 소리와 아이콘 파일, 그리고 `.ssz` 보드에서 설치된 파일. 스타일에 `title`이나 `resource-folder`가 있는 보드는 전용 하위 폴더를 가집니다.
- `%LocalAppData%\SimonSays\boards\`: 내보낸 보드의 기본 폴더, 자동 백업 `backup.ssz`, 그리고 SimonSays에 포함된 보드. 포함된 보드는 언어별 기본 문구와, `F9`나 📂 버튼으로 내 보드에 추가할 수 있는 기성 카테고리입니다. 기성 카테고리에는 예 / 아니요, 통증과 몸, 글자로 말하기, 게임, 질문, 일상 돌봄, 회의 템플릿, 청력 확인(내 언어로 된 이름)과, 모든 언어에서 쓸 수 있는 `Spelling_NATO`, `Alert_tones`, `Morse_code`가 있습니다. 모두 내 보드를 대체하지 않고 카테고리 하나를 추가합니다. 내 언어의 보드는 시작할 때와 설정에서 언어를 바꿀 때, 그 언어의 기본 보드가 없거나 바뀐 경우 이곳에 복사되어 폴더 안의 사본을 대체합니다. 그러니 편집한 보드는 새 이름으로 저장하세요.
- `%LocalAppData%\SimonSays\debug\`: 지원팀이 요청할 수 있는 진단 파일(`hid_dump.txt` 등).

이 폴더를 열려면 경로(예: `%LocalAppData%\SimonSays`)를 파일 탐색기의 주소 표시줄에 붙여 넣으세요.

## 문제 해결
- **음성 초기화에 실패함**: SAPI가 설치되어 있고 호환되는 음성이 있는지 확인하세요.
- **내 언어의 음성이 없거나, 문구가 다른 억양으로 말해짐**: SimonSays는 Windows에 설치된 음성을 사용합니다. Windows 설정(**시간 및 언어 → 음성 → 음성 관리**)에서 내 언어의 음성을 추가한 다음, SimonSays 설정(`F2`)에서 고르세요. Windows의 최신 "자연스러운" 음성 중 일부는 다른 앱에서 쓸 수 없을 수 있습니다.
- **소리가 재생되지 않음**: 파일 경로와 확장자, 그리고 `♫` 구분 기호가 짝을 이루는지 확인하세요.
- **SimonSays가 열려 있는 동안 작업 표시줄이 자동으로 숨겨지지 않음**: 의도된 동작입니다. SimonSays가 작업 표시줄 위에 있으므로 실행 중에는 작업 표시줄을 보이게 두고, 종료할 때 "작업 표시줄 자동으로 숨기기"를 다시 켭니다. 정전 등으로 SimonSays가 예기치 않게 닫혔다면, 다음에 SimonSays를 종료할 때 다시 켜집니다.
- **위젯 버튼이 SimonSays 막대를 가림**(Windows 11): Windows **설정 → 개인 설정 → 작업 표시줄**에서 위젯을 끄세요. SimonSays는 위젯을 처음 발견했을 때 그 페이지를 열어 줄지 한 번 묻습니다.
- **카테고리 창이 너무 작거나 너무 큼**: 빈 곳이나 창 가장자리를 두 번 클릭해 내용에 맞추거나, `F11` / `F12`로 확대/축소하세요.
- **카테고리나 문구가 사라짐**: 설정(`F2`)의 언어를 확인하세요. 언어마다 보드가 따로 있습니다. 가져오기로 보드가 대체되었다면 [변경 내용 되돌리기](#변경-내용-되돌리기)를 참조하세요.
- **"SimonSays가 카테고리와 문구를 저장하지 못했습니다"**: 변경 내용은 아직 표시되지만 SimonSays를 닫으면 사라질 수 있습니다. 바로 `F10`으로 보드를 내보내 사본을 보관하세요. 계속 일어나면 알려 주세요. 이 메시지는 편집할 때마다가 아니라 한 번만 나타나므로, 보드 사용을 방해하지 않습니다.
- **가져오기나 내보내기 오류**: 파일 권한과 디스크 위치를 확인한 뒤 다시 시도하세요.
- **언어나 음성 변경이 적용되지 않음**: 설정을 다시 열고 선택을 확인하세요. 그래도 적용되지 않으면 SimonSays를 다시 시작한 뒤 다시 시도하세요.
- **시선 추적기 문제 보고**: 지원팀이 진단 정보를 요청하면, 시선 / 응시 클릭 창(`F3`)을 열고 `진단 보고서 저장...`을 클릭하세요. 보고서(`hid_dump.txt`)가 `%LocalAppData%\SimonSays\debug\`에 저장되고 그 폴더가 열립니다. 보고서는 요청할 때만 만들어집니다.
