# SimonSays ヘルプガイド

## 概要
SimonSays は、Juan Rey Saura が作成した Windows 用の音声読み上げ (TTS) アシスタントです。ALS の方や、話すことができなくなった方が、コンピューターで行っている作業から離れずにすばやく会話できるようにするためのツールとして生まれました。やがて、同じ設計が、話すことが難しい、または話せないすべての方のための一般的な AAC (拡大・代替コミュニケーション) ツールとして役立つことがわかりました。たとえば構音障害、喉頭摘出、発語失行、脳卒中、脳損傷などが理由の場合です。すばやく話すこと、フレーズ ライブラリ、そしてテキストの途中でのサウンド再生に最適化されています。複数の言語、調整できる音声、効率的なコミュニケーションのための機能に対応しています。

SimonSays は Windows のタスク バーの空いている場所を使い、よく使う (カスタマイズできる) フレーズの十数個のカテゴリに、数回のクリックですばやくアクセスできます。ほかのウィンドウを隠すことがないので、ブラウザーや文書、ビデオ通話にとどまったまま、必要なときにいつでも話せます。キーボードでも、マウスでも、視線追跡装置を使って手を使わずにでも話せます。

使用例:
- 複数の Windows アプリを集中的に使いながら、コミュニケーションを途切れさせない。
- 言語聴覚士が、話すことに障害のある方のために作るボード。
- [Virtual CABLE](https://vb-audio.com/Cable/) を使ったオンライン会議 ([オンライン会議で SimonSays を使う](#オンライン会議で-simonsays-を使う)を参照)。

SimonSays は、Mind Express、TD Communicator、Grid 3、OptiKey のような本格的なコミュニケーション ソフトウェアや、それらに通常伴う専門的な評価や支援に代わるものではありません。役割はもっと限られていて、ほかのアプリで作業を続けながら、タスク バーからすばやく話すことです。これらのプログラムと一緒に使うこともできます。たとえば、OptiKey などの視線入力ソフトウェアでカーソルを動かし、SimonSays でフレーズを話すことができます。

SimonSays はオープンソースで無料です (価格だけでなく、自由という意味でもフリーです)。これからも変わりません。だれでも使い、調べ、改変し、共有できます。広告はなく、データも収集しません。

SimonSays はバージョン 1.0 に近づいています。その節目の前に、自分の音声、ボード、視線追跡装置を使って日常生活で試してくれる方が必要です。うまく動かないこと、使いにくいこと、足りないことがあれば、ぜひお知らせください ([フィードバック、サポート、プライバシー](#フィードバックサポートプライバシー)を参照)。どの声も役に立ちます。

## はじめに
1. SimonSays を起動します。Windows のタスク バーの空いている場所に表示され、通知領域にアイコンが追加されます。タスク バーは画面の下、上、左、右のどこにあってもかまいません。
   - タスク バーのアイコンが中央揃えのときは、SimonSays はタスク バーのいちばん先頭 (左端、または縦のタスク バーでは一番上) に置かれます。左揃えのときは、通知領域のすぐ手前に置かれます。
   - 小さい (細い) タスク バーでは、SimonSays のバーは低くなり、文字が小さくなって、2 つのクイック アクセス ボタンが横に並びます。画面の左右にあるタスク バーでは、コントロールが縦に積み重なります。
   - カテゴリ ウィンドウはタスク バーの横に開き、`カテゴリ` ボタンの矢印が開く方向を示します。
   - SimonSays の実行中にタスク バーを移動したりサイズを変えたりすると、数秒以内についていきます。
2. 話すには、次のどちらかを行います。
   - バーのテキスト ボックスをクリックします (または視線を止めます)。タスク バーの横に大きな入力ボックスが開きます。テキストを入力して `Enter` を押すと話します。ボックスが閉じてフォーカスが `再生>` に移るので、`スペース` でもう一度話す (または止める) ことができます。`Esc` を押すと、話さずにボックスを閉じて、使っていたウィンドウに戻ります。テキストはバーに残り、`再生>` でもう一度話せます。
   - カテゴリ ウィンドウで、保存してあるフレーズを 1 つ以上クリックします。
3. 再生中はボタンに `>` が表示されます。もう一度押すとすぐに止まります。

![タスク バー上の SimonSays のバー](img/bar.png)

`カテゴリ` ボタンの横にある 2 つの小さな **クイック アクセス ボタン** を使うと、ふだんはショートカット キーや通知領域のメニューから行う 2 つの操作を、1 回のクリックで行えます。

- 📂 はコンピューターに保存したボードを開きます。`F9` と同じインポートですが、ボード フォルダー (`%LocalAppData%\SimonSays\boards\`) から始まります。エクスポートしたボードやダウンロードしたボードはここに保存されます ([カテゴリのインポートとエクスポート](#カテゴリのインポートとエクスポート)を参照)。
- ⚙️ は `F2` と同じく設定を開きます。

設定 (`F2`) の `クイック アクセス ボタンとメニューを表示` で両方を非表示にでき、入力ボックスを広く使えます。同じ設定で、カテゴリ ウィンドウの右クリック メニューもオフになります。

SimonSays が非表示になっているときは、通知領域のアイコンをクリックするともう一度表示されます。

## カテゴリ ウィンドウ
![既定のフレーズを表示したカテゴリ ウィンドウ](img/categories.png)

- `カテゴリ` ボタンで開きます。サイズを変更できます。サイズを保つには、設定で `カテゴリ ウィンドウのサイズを記憶` をオンにします。
- 上のリストでカテゴリを、下のリストでフレーズを選びます。
- `選択したらすぐにフレーズを話す` がオンのときは、フレーズを 1 回クリックすると自動的に話します。オフのときは、話さずにメインの入力ボックスに読み込まれます。
- 空いている場所かウィンドウの端をダブルクリックすると、すべてのカテゴリとフレーズが収まるサイズに合わせます。
- 空いている場所をドラッグするとウィンドウが移動し、`Esc` を押すと非表示になります。
- `F12` と `F11` で拡大と縮小ができます ([ショートカット キー](#ショートカット-キー)を参照)。
- ボタンか空いている場所を右クリックする (または `Shift + F10` かメニュー キーを押す) と、`貼り付け`、`縮小`、`拡大`、`ズームをリセット`、`ヘルプ`、`設定`、`視線 / 注視クリック...`、`非表示`、`SimonSays を終了...` のメニューが開き、それぞれにショートカット キーが表示されます。最初の項目にはボードのタイトル (タイトルがない場合は `無題のボード`) が表示され、これを選ぶとボードのクレジット、言語、カテゴリとフレーズの数がわかります。このメニューは、設定で `クイック アクセス ボタンとメニューを表示` がオンのときだけ表示されます。
- カテゴリ ボタンやフレーズ ボタンの上では、そのボタンに対して、先に選択しなくても `編集...`、`左へ移動`、`右へ移動`、`新しいカテゴリを追加...` または `新しいフレーズを追加...`、`カテゴリを削除...` または `フレーズを削除...` も使えます。カテゴリの上では、`カテゴリをエクスポート...` でそのカテゴリだけを保存するかボード全体を保存するかを選べます。ショートカット キー `F4` ～ `F8` は、そのボタンが現在の選択のときに表示されます。これらのキーは選択に対して働くためです。空いている場所では、末尾にカテゴリを追加する `新しいカテゴリを追加...` が表示されます。空のボードを始めるときもこれを使います。
- カテゴリとフレーズの間の帯には、主なショートカット キーの案内 (ボードにキャプションがある場合はキャプション) が表示されます。

![フレーズ ボタンの右クリック メニュー](img/menu.png)

## 既定のフレーズ
SimonSays には、18 の言語それぞれにすぐ使えるカテゴリとフレーズのセットが用意されており、よく使うフレーズほど少ない選択で済むように並んでいます。

- 👋🏻 よくある挨拶
- 🗣️ 会話フレーズ
- 🚨 緊急時のフレーズ
- 🤲 ケアと快適さ
- 🏥 健康のフレーズ
- 🏠 家族と家
- 👥 社交のフレーズ
- ⏰ 時間と日付
- 💼 ビジネスのフレーズ
- ✈️ 旅行のフレーズ
- 🔊 音

言語ごとにカテゴリとフレーズがあります。設定 (`F2`) で言語を変えると、カテゴリ ウィンドウはその言語のボードに切り替わり、ある言語で行った変更はほかの言語には影響しません。

フレーズは Windows にインストールされている音声で話されます。お使いの言語の音声がインストールされていない場合も、フレーズは表示されますが、別の音声で話されることがあります ([トラブルシューティング](#トラブルシューティング)を参照)。

既定のフレーズは変更でき、あとで元に戻すこともできます。[カテゴリとフレーズの編集](#カテゴリとフレーズの編集)と[既定のフレーズを復元する](#既定のフレーズを復元する)を参照してください。

## ショートカット キー
- `F1`: ヘルプを開く
- `F2`: 設定を開く
- `F3`: 視線 / 注視クリックの設定
- `Enter`: 入力ボックスのテキストを話す
- `Esc`: カテゴリ ウィンドウを非表示にする
- `F11` / `Ctrl -`: 縮小 (カテゴリ ウィンドウ)
- `F12` / `Ctrl +`: 拡大 (カテゴリ ウィンドウ)
- `Ctrl + 0`: ズームをリセット
- `Shift + F10` またはメニュー キー: カテゴリ ウィンドウのメニューを開く (右クリックと同じ)
- `再生>` で `スペース`: テキストをもう一度話す、または再生中に止める

カテゴリ、フレーズ、ボードを編集するためのショートカット キーは、[カテゴリとフレーズの編集](#カテゴリとフレーズの編集)にあります。

## 設定 (F2)
設定 (`F2`) を開くと、次の項目を設定できます。設定画面は 2 列になっています。

![設定ウィンドウ](img/settings.png)

**左の列**
- **既定のテキスト**: `既定のテキストを自動挿入` のオン/オフを切り替え、既定のフレーズをカスタマイズします。
  - `タッチ キーボードを表示`: 入力ボックスが開くときに画面のタッチ キーボードを開きます。タッチ キーボードは入力ボックスの横、タスク バーから遠い側に置かれます。
- `クイック アクセス ボタンとメニューを表示`: メイン ウィンドウの `カテゴリ` ボタンの横に 📂 (ボードを開く) と ⚙️ (設定) のボタンを表示し ([はじめに](#はじめに)を参照)、カテゴリ ウィンドウの右クリック メニューも有効にします ([カテゴリ ウィンドウ](#カテゴリ-ウィンドウ)を参照)。オフにするとこれらがすべて非表示になり、入力ボックスを広く使えます。
- **カテゴリ ウィンドウ**:
  - 選択後に `カテゴリ ウィンドウを自動的に最小化`。
  - `カテゴリ ウィンドウのサイズを記憶`。
  - `カテゴリ ウィンドウのサイズを内容に合わせて自動調整`: カテゴリとフレーズが読み込まれるたびに、カテゴリ ウィンドウをそれに合わせます。たとえば、起動時、言語の変更後、インポート後などです。
- `視線 / 注視クリック...`: 設定の上に[視線 / 注視クリック](#視線--注視クリック-f3)の設定を開きます。設定は変更内容を保ったまま開いたままになります。そこで行った変更は、そのウィンドウで `OK` を押したときに保存され、あとで設定の `キャンセル` を押しても保存されたままです。

**右の列**
- **言語**: インターフェイスの言語を選びます (English、Español、العربية、Euskara、Català、简体中文、Français、Galego、Deutsch、עברית、हिन्दी、Italiano、日本語、한국어、Português、Português (Brasil)、Русский、Valencià)。言語ごとにカテゴリとフレーズもあります ([既定のフレーズ](#既定のフレーズ)を参照)。
- **音声**: お使いの言語に合った、インストール済みの SAPI 音声を選びます。
- **音量/速度**: `音量 (10-100)` と `速度 (-10 ～ 10)` を調整します。
- `音声をテスト`: 選んだ音声を試聴します (`音声出力` で選んだデバイスから再生されます)。
- `音声出力`: SimonSays が音声とサウンドを再生する場所です。`Windows の既定` (通常の選択) か、接続されている任意のデバイスを選べます。仮想オーディオ ケーブルがリストの先頭に表示されます。[オンライン会議](#オンライン会議で-simonsays-を使う)にはこれが必要です。選んだデバイスが接続されていない場合、SimonSays は Windows の既定のデバイスで再生し、1 回だけお知らせします。選択は保持されて `(未接続)` と表示され、デバイスが戻るとすぐにまた使われます。
- `聴く設定...`: Windows の録音デバイスを開きます。ここで仮想ケーブルの **このデバイスを聴く** をオンにできます ([オンライン会議で SimonSays を使う](#オンライン会議で-simonsays-を使う)を参照)。
- **再生の動作**:
  - `選択したらすぐにフレーズを話す` (1 回のクリックで自動的に話す)。
  - `前の再生を停止`: 新しいフレーズを始める前に、再生中のものを自動的に止めます。
  - `再生中に SimonSays の音量を上げる`: 話している間、SimonSays が再生に使うデバイス (`音声出力` を参照) の音量を上げ、終わると元の音量に戻します。
  - `再生中に他の音声を一時的に下げる`: 話している間、ほかのアプリの音量を下げ、終わると元に戻します。

**下部**
- `ヘルプ` (左下、または設定を開いているときに `F1`) は、`言語` リストで選んだ言語でこのヘルプを開きます。設定は変更内容を保ったまま開いたままです。
- `OK` で変更を保存し、`キャンセル` で破棄します。

既定では、`選択したらすぐにフレーズを話す`、`カテゴリ ウィンドウを自動的に最小化`、`カテゴリ ウィンドウのサイズを内容に合わせて自動調整`、`再生中に SimonSays の音量を上げる`、`再生中に他の音声を一時的に下げる` がオンで、`前の再生を停止` はオフです。

## 視線 / 注視クリック (F3)
フレーズやボタンに視線 (またはマウス カーソル) を決まった時間止めると、手を使わずにそれを押せます。これは新しい機能で、テストとフィードバックが必要です。お使いのトラッカーでどう動くかを、通知領域メニューの `フィードバック` からお知らせください。

対応している構成:
- **マウス カーソルを動かす視線入力ソフトウェアすべて** (Irisbond EasyClick、Tobii Dynavox Computer Control、Windows の視線制御のカーソル モード、OptiKey): 注視クリックはカーソルに従います。
- **視線を直接読み取る方式 (カーソルを動かす必要はありません)**: Irisbond Hiru (HID モード) と、それぞれのソフトウェアを使う Tobii のトラッカー。Tobii Eye Tracker 4C、Tobii Eye Tracker 5、Tobii Dynavox PCEye 5 で確認済みです。
- **Tobii Eye Tracker 5**: 現在のソフトウェアは 64 ビットのエンジンしかインストールしないため、SimonSays は横にインストールされる小さな補助プログラム `SimonSaysGaze64.exe` を通して読み取ります。補助プログラムは必要なときだけ起動し、ウィンドウはなく、SimonSays と一緒に終了し、視線のデータをお使いのコンピューターから出しません。保存されることも、どこかに送られることもありません。
- **Tobii Eye Tracker 4C と Eye Tracker 5 のライセンス**: これらのトラッカーに対する Tobii のエンド ユーザー ライセンスでは、病院やその他の医療現場での使用を含め、医療目的での使用は認められていません。PCEye 5 などの Tobii Dynavox の機器には、それぞれ独自のライセンス条件があります。
- **Tobii Eye Tracker 4C のソフトウェア**: SimonSays は Tobii Core を通して 4C を読み取ります。同じコンピューターに Eye Tracker 5 を接続すると、Windows が Tobii Experience をインストールし、これが Tobii Core をオフにするため、4C は動かなくなります。4C をまた使うには、Tobii Core を再インストールしてください。推奨バージョンは `Tobii_Eye_Tracking_Core_v2.13.1.7294_x86.exe` で、[Tobii のスタート ページ](https://gaming.tobii.com/getstarted/)から入手できます。

注視クリックが働く場所:
- SimonSays のバー、カテゴリ ウィンドウ、そのフレーズ ボタンとカテゴリ ボタン。
- SimonSays 自身のウィンドウや質問のボタン。設定、視線 / 注視クリックのウィンドウ、追加・編集・プレビューのダイアログ、そして `はい` / `いいえ` や `OK` / `キャンセル` などのすべての確認です。これらのボタンはお使いの言語で表示され、ウィンドウが開いてから約 0.75 秒たってから注視に反応し始めます。見ている場所にちょうど出てきた質問が、ひとりでに答えてしまわないようにするためです。
- 視線を直接読み取っているときは、見ているボタンがマウスを重ねたときと同じように光るので、進行状況が始まる前に何を選ぼうとしているかがわかります。まばたきしても強調表示は残り、目をそらすと消えます。

![視線 / 注視クリックのウィンドウ](img/dwell.png)

視線 / 注視クリックの設定 (`F3`、通知領域のメニュー、または設定の `視線 / 注視クリック...` ボタン) を開くと、次の項目を設定できます。
- **動作モード**: 次のいずれかを選びます。
  - `自動`: 接続されているデバイスを検出し、状況に応じてマウス カーソルまたは視線の検出で注視クリックを有効にします。バックグラウンドで動く Tobii のソフトウェア (インストール後は常に実行中) だけでは、カーソルでの注視はオンになりません。Tobii のトラッカーは、実際に視線を追跡しているときだけ使われます。
  - `マウス カーソル`: 常にマウス カーソルで注視クリックを有効にします。
  - `HID 視線追跡装置`: 常に視線の検出で注視クリックを有効にします (HID モードの Irisbond Hiru、または Tobii のトラッカー)。ボタンを押せるのは視線だけです。視線のデータが届かない間 (追跡がオフ、またはトラッカーが外れている) は、注視で何も押されず、マウスはふつうに使えます。
  - `オフ`: 常に注視クリックを無効にします。
  - **ロックオン遅延**: 進行状況バーが始まる前に、視線 (またはカーソル) がボタンの上にとどまる必要がある時間 (ミリ秒、既定は 150)。これにより、ボタンの上を視線が通り過ぎても進行状況はまったく表示されません。ボタンはロックオン遅延と注視時間の合計のあとに押されます。0 にすると、進行状況がすぐに始まります。
  - **注視時間**: 要素を見つめてクリックするのに必要な時間 (ミリ秒、既定は 500)。注視している間は進行状況の表示が出ます。
  - **許容半径**: 視線の許容範囲 (ピクセル)。小さな目の動きがあっても注視が途切れないようにします。
  - **クールダウン**: 押したあと、注視クリックがもう一度働かないミリ秒数 (うっかり何度もクリックするのを防ぎます)。
  - **進行状況の色**: 注視の進行状況の表示の色 (既定は Windows のアクセント カラー)。
  - **注視で再び押す前に一度離れる** (既定でオン): 注視クリックのあと、ポインターや視線がその場所から離れる (許容半径より外に出る) か、少しの間目をそらすまでは、どのボタンも注視でもう一度押されることはありません。ボタンの上にとどまっても押されるのは 1 回だけなので、長いフレーズが終わる前にくり返されることはありません。マウスのクリックには影響しません。
  - **トラッカーの使い方を検出**: 視線追跡装置でマウス カーソルを動かしているのか、ボタンをクリックしているだけなのかを、アプリが判断するための 2 つのボタン。
  - **検出結果**: 検出されたデバイスの種類と、関連するソフトウェアの詳しい情報を表示します。
  - `診断レポートを保存...` (検出結果の下): お使いの視線追跡装置とそのソフトウェアについてのレポートを `hid_dump.txt` に書き出し、そのフォルダーを開きます。サポートに送ることができます。
  - `リセット` ボタン (左下) で、注視の設定をすべて既定値に戻します。
  - `OK` ボタンで変更を保存し、`キャンセル` で破棄します。

## オンライン会議で SimonSays を使う
SimonSays は、ビデオ通話 (Teams、Zoom、Google Meet…) の中で直接話すことができ、ほかの参加者にはマイクから話しているように聞こえます。それには、無料の [VB-Audio Virtual Cable](https://vb-audio.com/Cable/) のような仮想オーディオ ケーブルが必要です。

1. 仮想オーディオ ケーブルをインストールし、求められたら Windows を再起動します。
2. SimonSays の音をケーブルに送ります。設定 (`F2`) を開き、`音声出力` で `CABLE Input` を選びます (仮想ケーブルはリストの先頭にあります)。`音声をテスト` を押して確認します。音はケーブルに送られるようになったので、スピーカーからは聞こえなくなるはずです。
3. 会議アプリで、マイクとして `CABLE Output` を選びます。
4. 自分でも SimonSays を聞くには、設定の `聴く設定...` を押します。Windows の録音デバイスが開くので、`CABLE Output` を選んで **プロパティ → 聴く** を開き、**このデバイスを聴く** をオンにして、**このデバイスを使用して再生する** でスピーカーかヘッドセットを選び、`OK` を押します。これは 1 回だけ行えば十分です。

SimonSays が代わりに **このデバイスを聴く** をオンにすることはできません。これはケーブルの録音側の設定で、Windows はユーザー本人にしか変更させないため、`聴く設定...` で正しいウィンドウを直接開くようにしています。

知っておくと便利なこと:
- Windows の既定の再生デバイスは、`CABLE Input` ではなく、スピーカーかヘッドセットのままにしてください。**このデバイスを聴く** の再生先が「既定の再生デバイス」で、その既定のデバイスがケーブルになっていると、音がケーブルに戻ってループします。
- 会議でフレーズは聞こえるのに効果音 (拍手、ドアのチャイム) が聞こえない場合は、会議アプリのノイズ抑制が取り除いています。アプリでノイズ抑制を弱めるかオフにしてください。
- ケーブルがアンインストールされたり外れたりすると、SimonSays は Windows の既定のデバイスで再生し、1 回だけお知らせします。ケーブルがまた使えるようになると、すぐにケーブルに戻ります。
- 通話用のフレーズを用意するには、**会議用テンプレート** のカテゴリを追加します。`F9` か 📂 ボタンを押し、お使いの言語の名前のボードを開きます (日本語では `SimonSays_会議用テンプレート_(日本語).ssc`)。挨拶、「聞こえますか？」、プログラムを使って話していることの短い説明、はい / いいえ、賛成 / 反対、くり返しやゆっくり話すことのお願い、別れの挨拶が入っています。自分の会議用のフレーズを追加するように編集してください。
- 手順 2 の代わりに、Windows のアプリごとの設定 (**設定 → システム → サウンド → 音量ミキサー**) で SimonSays の出力先を変え、`音声出力` は `Windows の既定` のままにしておくこともできます。SimonSays は、何かを再生したあとでなければこのリストに表示されません。

## カテゴリとフレーズの編集
このセクションとそれ以降のセクションは、ボードのカテゴリ、フレーズ、サウンド、外観を変更する介助者、言語聴覚士、上級ユーザー向けです。変更はすべてすぐに保存されます ([変更を元に戻す](#変更を元に戻す)を参照)。

### どのエディターを使うか
- **SimonSays で**: 日々の変更。カテゴリやフレーズの名前の変更、追加、移動、削除、絵文字の設定、サウンドの追加、フレーズの一覧の貼り付け、色の調整など。このセクションの残りで方法を説明します。
- **[SimonSays Web](https://github.com/juan-rey/simonsays-web) で**: ボードの大きな作業。こちらのほうがずっと簡単です。AAC 用のピクトグラムで作るボード (ARASAAC のピクトグラム ライブラリを検索できます)、独自のアイコン画像、色やサイズ、レイアウトを設定したボードなどです。単語のグループごとに色を決める **Fitzgerald Key** のボードを作るときには特におすすめします。`.ssc`/`.ssz` のボードをアップロードせずにブラウザーの中で直接開いて保存できるビジュアル エディターです。作業が終わったら、`F9` か 📂 ボタンで SimonSays にボードをインポートします。SimonSays のボードをほかのプラットフォームで使うときにも使えます。

編集用のショートカット キー (カテゴリ ウィンドウ):
- `F4`: 現在の選択を編集
- `F5` / `F6`: リスト内の前 / 次の項目へ移動
- `F7`: 現在の選択の後ろに追加 (状況に応じてカテゴリまたはフレーズ)
- `F8`: 現在の選択を削除
- `F9`: カテゴリをインポート
- `F10`: カテゴリをエクスポート
- `Ctrl + F4`: ボードのスタイルを編集 ([外観のカスタマイズ](#外観のカスタマイズ-ボードとカテゴリのスタイル)を参照)
- `Ctrl + F8`: すべてのカテゴリとそのフレーズを削除 (2 回確認します)
- `Ctrl + V` または `Shift + Insert`: コピーしたテキストを、段落ごとに 1 つのフレーズとして追加 ([フレーズの管理](#フレーズの管理)を参照)
- `.txt`、`.ssc`、`.ssz` ファイルをウィンドウにドラッグ: `.txt` は新しいカテゴリとして追加し、ボードは `F9` と同じようにインポートします ([カテゴリの管理](#カテゴリの管理)を参照)

> **ヒント:** `Ctrl + F8` を使う前や、ボード全体をインポートする (`F9`) 前に、ボードをエクスポートしておく (`F10`) と、元に戻せます。

### カテゴリの管理
- 名前の変更: カテゴリを選ぶ → (ショートカット: `F4`) `カテゴリ名を変更` → 名前を変える → `OK`。
- 選択の移動: リストを見ながら `F5`/`F6` で前/次の項目へ移ります。
- 追加: カテゴリを選ぶ → (ショートカット: `F7`) `新しいカテゴリを追加` ダイアログ → 名前を入力 → `OK`。
- 削除: カテゴリを選ぶ → (ショートカット: `F8`) `カテゴリを削除` → カテゴリとそのフレーズを削除することを確認します。
- テキスト ファイルから追加: `.txt` ファイルをカテゴリ ウィンドウにドラッグ → ファイル名のカテゴリが作られ、段落ごとに 1 つのフレーズになります (段落は空行で区切ります) → プレビューを確認 → `OK`。複数のファイルを一度にドロップでき、それぞれにプレビューが出ます。既存のカテゴリと同じ名前のファイルは受け付けられません。
- ドラッグしてボードを開く: `.ssc` か `.ssz` ファイルをカテゴリ ウィンドウにドラッグ → SimonSays がインポートするかどうかを尋ねます。`はい` を選ぶと `F9` と同じようにインポートされます ([カテゴリのインポートとエクスポート](#カテゴリのインポートとエクスポート)を参照)。ファイルにボード全体が入っている場合は現在のボードと置き換わり、その前に現在のボードのコピーが `backup.ssz` として保存されます。テキスト ファイルとボード ファイルを一緒にドロップでき、順番に処理されます。エクスプローラーから `.ssc` か `.ssz` ファイルを開いた (ダブルクリックした) ときも、同じことを尋ねます。

#### カテゴリのアイコンの設定と変更
カテゴリのボタンには、絵文字か独自の画像ファイル (`.ico`、`.png`、`.jpg`) を表示できます。追加・編集のダイアログで、区切りの接頭辞 `##` を使ってアイコンを指定します。

```
<アイコン>##<カテゴリ名>
```

- **絵文字**: 絵文字 (1 つ以上) のあとに `##` と名前を入力します。
  - 例: `🙂##挨拶`
- **アイコン ファイル** (`.ico`、`.png`、`.jpg`): ファイル名かフル パスのあとに `##` と名前を入力します。フォルダーを含まないファイル名は、[サウンドとアイコンのファイルの検索順序](#サウンドとアイコンのファイルの検索順序)のとおりに検索されます。
  - 例: `C:\icons\smile.png##挨拶`
- **アイコンなし**: `##` を付けずにカテゴリ名だけを入力します。
  - 例: `挨拶`

> 注: ファイルのアイコンに使えるのは `.ico`、`.png`、`.jpg` だけです。ほかの拡張子は無視され、アイコンは表示されません。PNG 画像は透明部分が保たれます。とても大きな画像は、読み込むときに自動的に縮小されます。

### フレーズの管理
- 編集: フレーズを選ぶ → (ショートカット: `F4`) `フレーズを編集` → テキストを修正 → `OK`。
- 選択の移動: `F5`/`F6` で前/次のフレーズへ移ります。
- 追加: フレーズを選ぶ → (ショートカット: `F7`) `新しいフレーズを追加` → テキストを入力 → `OK`。
- 削除: フレーズを選ぶ → (ショートカット: `F8`) `フレーズを削除` → 確認します。
- まとめて追加: フレーズを空行で区切ったテキストをコピー → フレーズ (またはカテゴリ) を選ぶ → `Ctrl + V` → プレビューを確認 → `OK`。フレーズは選んだフレーズの後ろ、またはカテゴリの末尾に追加されます。段落の中の改行は空白になり、アイコンの `##` と音声の `::` は `新しいフレーズを追加` ダイアログと同じように働きます。
- サウンドの追加: `.wav` か `.mp3` ファイルを 1 つ以上カテゴリ ウィンドウにドラッグ → プレビューを確認 → `OK`。各ファイルはファイル名のサウンド フレーズになって、選んだフレーズの後ろ (または選んだカテゴリの末尾) に追加されます。ファイルはボードのリソース フォルダーにコピーされるので、ボードをエクスポートするときに一緒に持ち運べます。既存のファイルが上書きされることはありません。同じ名前の別のサウンドがすでにある場合、新しいほうは `name (2).wav` として保存されます。

#### フレーズのアイコンの設定と変更
フレーズにも、カテゴリと同じアイコン接頭辞のルールが使えます。フレーズのテキストの前に、省略できる区切り `##` を置きます。

```
<アイコン>##<フレーズのテキスト>
```

- **絵文字**: `👍##いいですね！`
- **アイコン ファイル**: `C:\icons\check.png##いいですね！`
- **アイコンなし**: `いいですね！`

フレーズには音声ファイルを含めることもできます ([音声とサウンドの組み合わせ](#音声とサウンドの組み合わせ)を参照)。アイコン、テキスト、音声を組み合わせるには、次の形式を使います。

```
<アイコン>##<フレーズのテキスト>::<音声ファイル>
```

- 例: `🔔##注意::alert.mp3`

接頭辞 `##` と接尾辞 `::` はどちらも省略でき、互いに独立しています。どの組み合わせでも使えます。
- アイコンの接頭辞だけ: `🔔##注意`
- 音声の接尾辞だけ: `注意::alert.mp3`
- 両方: `🔔##注意::alert.mp3`
- どちらもなし: `注意`

## 音声とサウンドの組み合わせ
- 区切り文字 `♫` を使って、テキストの中に音声ファイル名を入れます。
  - 例: `こんにちは ♫doorbell.mp3♫ 少々お待ちください。`
  - 区切り文字の外のテキストは読み上げられ、中のテキストはサウンド ファイルとしてその位置で再生されます。
- 対応している音声: `.wav` と `.mp3`。MIDI ファイル (`.mid`、`.midi`) はフレーズに書けますが再生されません。`.wav` か `.mp3` に変換してください。
- プログラムがアクセスできる絶対パスか相対パスを使ってください。区切り文字は必ず対にして、残りのテキストが音声として扱われないようにしてください。
- `♫` を入力するには、このヘルプからコピーするか、サウンドのあるフレーズを選びます。そのフレーズの `♫…♫` が入力ボックスに入るので、前後にテキストを追加できます。

### SimonSays に付属のサウンド
これらのサウンドは SimonSays と一緒にインストールされ、名前を書けばどのテキストやフレーズでも使えます。たとえば入力ボックスで `♫laugh.mp3♫`、または「よくできました！」と表示されて拍手を再生するフレーズ ボタンなら `よくできました！::applause.mp3` です。

`ahem.mp3`, `alert.mp3`, `applause.mp3`, `aww.mp3`, `beep.mp3`, `boo.mp3`, `call_bell.mp3`, `censor.mp3`, `doorbell.mp3`, `drumroll.mp3`, `evil_laugh.mp3`, `fail.mp3`, `hmmmm.mp3`, `kisses.mp3`, `laugh.mp3`, `mmm-hmm.mp3`, `nuh-uh.mp3`, `phone_ring.mp3`, `rimshot.mp3`, `scream.mp3`, `shots.mp3`, `sigh.mp3`

### サウンドとアイコンのファイルの検索順序
サウンドやアイコンのファイル名にドライブ文字やフル パスが含まれていない場合、SimonSays は次の順に探し、最初に見つかったものを使います。

1. **現在のボードのリソース サブフォルダー**: ボードのスタイルで `title` か `resource-folder` が設定されている場合、リソース フォルダーの中にあるそのボード専用のサブフォルダー ([外観のカスタマイズ](#外観のカスタマイズ-ボードとカテゴリのスタイル)を参照)。
2. **リソース フォルダー**: `%LocalAppData%\SimonSays\resources\` (ボードのアイコンとサウンドの標準の置き場所です。インポートした `.ssz` パッケージはここにファイルをインストールします)。
3. **SimonSays のデータ フォルダー**: `%LocalAppData%\SimonSays\` (リソース フォルダーができる前に、以前のバージョンがここに置いたファイルのために残してあります)。
4. **作業ディレクトリ**: プロセスの現在の作業ディレクトリ (プログラムのフォルダーと異なる場合だけ探します)。
5. **プログラムのフォルダー**: `SimonSays.exe` があるフォルダー。

どの場所にも見つからない場合は、組み込みの代替サウンドが使われます (アイコンは単に表示されません)。

> **ヒント:** 独自のサウンドやアイコンのファイルは `%LocalAppData%\SimonSays\resources\` に置くことをおすすめします。アプリを更新しても残り、ユーザーごとに分かれます。スタイルで `title` か `resource-folder` を設定したボードには、そこに自動的に専用のサブフォルダーが作られ、ほかのボードのファイルと分けて保管されます。

## 外観のカスタマイズ (ボードとカテゴリのスタイル)
カテゴリ ウィンドウとそのボタンの色、大きさ、スタイルを変えられます。たとえば、Fitzgerald Key のような色分けしたコミュニケーション ボードを作るときに使います。スタイルは必須ではありません。スタイルがなければ、ウィンドウは既定の外観のままです。

> **ヒント:** 以下の内容はすべて SimonSays で入力できるので、ちょっとした調整に便利です。スタイルを設定したボードやピクトグラムのボードを丸ごとデザインするには、[SimonSays Web](https://github.com/juan-rey/simonsays-web) をおすすめします。作業しながら結果を確認でき、これらのスタイルを自動的に書いてくれます ([どのエディターを使うか](#どのエディターを使うか)を参照)。

スタイルは `property:value;` の組の並びです。値には次のものが使えます。
- **色**: 16 進数の `#RRGGBB`。例: `#FFD966`。
- **サイズ**: ピクセル数 (`96`) か、既定値に対する割合 (`120%`)。
- **キーワード**: 例: `left`、`right`、`top`、`bottom`、`smart`、`normal`、`bold`。
- **テキスト**: フォント名、またはキャプション、タイトル、クレジットのテキスト。

アプリが認識できないもの (つづりを間違えたプロパティや不正な値) は無視されるだけなので、スタイルでウィンドウが壊れることはありません。

### 1 つのカテゴリのスタイル (編集ウィンドウ)
カテゴリを選んで `F4` (編集) を押し、名前の後ろに `::` とスタイルを追加します。

```
<アイコン>##<カテゴリ名>::<property>:<value>;<property>:<value>;
```

- 例: `🧍##人::background:#FFD966;` は「人」ボタンを黄色にします。カテゴリの色は **その中のフレーズにも適用される** ので、1 行で単語のグループ全体に色が付きます。これが Fitzgerald Key のボードの基本です。
- カテゴリのスタイルでは、カテゴリ ボタンの `background` と `text-color` を設定できるほか、フレーズのプロパティ (下記を参照) に `phrase-` を付けて設定できます。例: `phrase-corner-radius:8;`。

### ボード全体のスタイル (`$$board`)
全体の外観 (ウィンドウの背景、区切り線、すべてのカテゴリ ボタンとフレーズ ボタンの既定値) は **ボードのスタイル** です。予約されたカテゴリ名 `$$board` で保存されます (自分のカテゴリに `$$` で始まる名前は使えません)。

- カテゴリ ウィンドウで `Ctrl + F4` を押すと **編集** できます。エディターには 1 行に 1 つの `property:value;` が表示されます。`OK` で確定すると新しいスタイルが適用され、SimonSays が「変更を元に戻しますか？」と尋ねます。前のスタイルに戻すには `OK`、新しいスタイルを残すには `キャンセル` を選びます。
- スタイル付きのカテゴリ ファイル (`.ssc` / `.ssz`) をインポートして **スタイルを手に入れる** こともできます。ボードのスタイルを含むファイルをインポートすると、SimonSays は今のスタイルを置き換える前に確認し、インポートのメッセージにボードの `title` と `credits` (あれば) を表示します。ボードのスタイルで `title`、`credits`、`language`、`resource-folder` しか設定していないファイルは、見た目を何も変えないので、SimonSays は確認しません。カテゴリが 1 つだけならそれが追加されて外観はそのまま、ボード全体ならほかのボード全体と同じように外観ごと置き換わります。

### スタイルのプロパティ
- **ウィンドウ全体**: `background`、`separator-color`、`text-color`、`font-name`、`font-size`、`text-weight`、`caption` (区切り線の間に表示するキャプション)、`title` と `credits` (ボードのインポート時に表示)、`language` (ボードを作った対象の言語。例: `language:Japanese`。設定している言語が違う間は SimonSays はボードのインポートを断り、設定 (`F2`) でどの言語に切り替えればよいかを伝えます)。
- **すべてのカテゴリ ボタン** (接頭辞 `category-`) と **すべてのフレーズ ボタン** (接頭辞 `phrase-`): `background`、`text-color`、`width`、`height`、`corner-radius`、`border-width`、`margin`、`icon-position` (`left`/`right`/`top`/`bottom`/`center`)、`icon-size`、`font-name`、`font-size`、`text-weight`、`text-layout`。

`icon-position` を `center` にすると、アイコンがボタンの中央に置かれてテキストは非表示になります (アイコンだけのキー)。アイコンを上、名前をその下にしたい場合は `top` を使ってください。中央のアイコンの上にテキストも表示したい場合は、`text-layout` をはっきり指定すると (例: `text-layout:bottom`)、その位置に表示されます。

`text-layout` には、横方向 (`left`/`center`/`right`) と縦方向 (`top`/`middle`/`bottom`) のキーワードのどちらか、または両方、あるいは `smart` を指定します。既定は smart で、アイコンが残したスペースの中央にテキストを置きます (アイコンが上 → キャプションはその下の中央。アイコンがなければボタン全体の中央)。

### 例: 色分けした Fitzgerald Key ボード
6 つの単語グループに色を付けるには、それぞれのカテゴリを編集して (`F4`) 背景色を 1 つ付けます。編集ダイアログに入力する文字列は次のとおりです。

```
🧍##人::background:#FFD966;
🏃##動作::background:#93C47D;
📏##様子::background:#6FABDC;
🍎##もの::background:#F6B26B;
🕒##その他::background:#FFFFFF;
👋##あいさつ::background:#B4A7D6;
```

それぞれの色はそのカテゴリのフレーズにも付くので、ボード全体が色分けされます。ボード全体の仕上げ (各カテゴリの絵文字を上に、名前をその下に置く、区切り線に色を付けるなど) は、次のようなボードのスタイル (`Ctrl + F4`) で行います。

```
category-icon-position:top;separator-color:#B4A7D6;
```

すべてのキーにピクトグラムがあり、フレーズを単語のグループごとに並べた本格的な Fitzgerald Key のボードは、[SimonSays Web](https://github.com/juan-rey/simonsays-web) で作って `F9` でインポートしてください。

スタイルはカテゴリと一緒に移動します。エクスポート (`F10`) にはスタイルが含まれ、インポート (`F9`) でスタイルも取り込まれるので、スタイル付きのボードを 1 つのファイルとして共有できます。

## カテゴリのインポートとエクスポート
ボードは、`.ssc` ファイル (カテゴリとフレーズ) か `.ssz` ファイル (同じ内容に、使っているサウンドとアイコンのファイルを加えた 1 つのファイル) として共有します。[SimonSays Web](https://github.com/juan-rey/simonsays-web) を使えば、ブラウザーで見ながら作成・編集することもできます。

- **エクスポート** (`F10`): 尋ねられたら、すべてのカテゴリをエクスポートするか、選んだカテゴリだけをエクスポートするかを選びます。保存のダイアログは既定で `%LocalAppData%\SimonSays\boards\` で開きますが、どこにでも保存できます。カテゴリやフレーズが、SimonSays が見つけられるサウンドやアイコンのファイルを使っている場合は、自動的に `.ssz` で保存されます (`.mid`/`.midi` のサウンドは含まれません)。すべてのカテゴリをエクスポートするとボードのスタイルも含まれ、1 つのカテゴリをエクスポートするとそのカテゴリのスタイルだけが含まれます。成功や失敗のメッセージは、選んだ言語で表示されます。
- **インポート** (`F9`): `.ssc` か `.ssz` ファイルを選びます。
  - **複数のカテゴリかボードのスタイル** を含むファイルはボード全体です。**現在の言語のすべてのカテゴリとフレーズを置き換えます**。その前に、それまでのボードが `backup.ssz` として保存されます ([変更を元に戻す](#変更を元に戻す)を参照)。
  - **カテゴリが 1 つだけ** のファイルはボードに追加されます。同じ名前のカテゴリがすでにある場合は、上書きするかどうかを尋ねられます。ファイルがボードの名前 (`title`、`credits`、`language`) しか設定しておらず、色やサイズ、フォントがない場合も同じです。こうした情報でボードやその外観が置き換わることはありません。
  - `.ssz` の中のサウンドとアイコンのファイルはリソース フォルダーにインストールされ、カテゴリ ウィンドウはインポートしたボードに合わせてサイズが変わります。成功や失敗のメッセージは、選んだ言語で表示されます。

## 変更を元に戻す
SimonSays は変更をすべてすぐに保存し、一般的な「元に戻す」コマンドはありません。元に戻すには、次の方法があります。

- **インポートを元に戻す**: インポートでボードが置き換わる前に、SimonSays はそれまでのボードを `%LocalAppData%\SimonSays\boards\` に `backup.ssz` として保存します。インポートを元に戻すには、`F9` を押して `backup.ssz` を選びます。それまでのボードが、カテゴリも外観もそのまま、ほかに何も尋ねられずに戻ります。保存されるのは最後に置き換わったボードだけで、ボード全体を新しくインポートするたびにバックアップは上書きされます。
- **ボードのスタイルの変更を元に戻す**: `Ctrl + F4` でボードのスタイルを編集したあと、SimonSays が「変更を元に戻しますか？」と尋ねます。前のスタイルに戻すには `OK` を選びます。
- **カテゴリやフレーズの変更を元に戻す**: `F4`、`F7`、`F8` で行った変更は自動的には元に戻せません。大切なボードを大きく変更する前に、エクスポートしておいてください (`F10`)。あとでそのファイルをインポートすれば (`F9`)、その時点に戻れます。

### 既定のフレーズを復元する
SimonSays が自分のカテゴリやフレーズを上書きすることはありません。そのため、更新で追加された新しい既定のフレーズは、まだ使っていない言語にしか表示されません。組み込みのカテゴリとフレーズには、いつでも戻せます。たとえば、最初からやり直したいときや、更新で追加された新しいフレーズを使いたいときです。この操作は **現在の言語のボード全体を置き換えます**。

1. `カテゴリ` の横の 📂 ボタンをクリックします (またはカテゴリ ウィンドウで `F9` を押します)。ボード フォルダーが開きます。
2. お使いの言語の既定のフレーズのボードを選びます。日本語では `SimonSays_既定のフレーズ_(日本語).ssc` です (ほかの言語でも、その言語で同じ形の名前になっています。例: `SimonSays_default_phrases_(English).ssc`)。
3. インポートを確認します。その前に現在のボードが `backup.ssz` として保存されるので、あとで取り戻すこともできます ([変更を元に戻す](#変更を元に戻す)を参照)。

このボードには、実行している SimonSays のバージョンの既定のフレーズが常に入っています。SimonSays は、起動時と言語を変えたときに、ボード フォルダーのこのファイルを更新します。自分のボードを残したい場合は、先に好きな名前でエクスポートしてください (`F10`)。`backup.ssz` は次のインポートで上書きされます。

ボード フォルダーにファイルがない場合は、最後の手段があります。SimonSays を終了し (通知領域のメニュー → `終了`)、レジストリ エディター (`regedit`) を開いて、`HKEY_CURRENT_USER\SOFTWARE\SimonSays\Phrases\` の下にある、お使いの言語の英語名のキー (例: `Japanese`) を削除してから、SimonSays をもう一度起動します。その言語の既定のカテゴリとフレーズが、バックアップなしで作り直されます。

`Portuguese (Brazil)` の場合: `Portuguese` キーもあると、SimonSays はブラジル ポルトガル語の既定のフレーズを作る代わりに、そのボードを `Portuguese (Brazil)` にコピーします。そのため `Portuguese` キーも削除してください (使っている場合は先にエクスポートしてください)。

## SimonSays がファイルを保存する場所
- **カテゴリ、フレーズ、設定** は、Windows のレジストリの `HKEY_CURRENT_USER\SOFTWARE\SimonSays` に保存されます (各言語のボードは `Phrases\<Language>` の下)。
- `%LocalAppData%\SimonSays\resources\`: 自分のサウンドとアイコンのファイル、および `.ssz` のボードからインストールされたファイル。スタイルで `title` か `resource-folder` を設定したボードには、専用のサブフォルダーがあります。
- `%LocalAppData%\SimonSays\boards\`: エクスポートしたボードの既定のフォルダー、自動バックアップの `backup.ssz`、SimonSays に付属するボード。付属のボードは、各言語の既定のフレーズと、`F9` か 📂 ボタンでボードに追加できる既製のカテゴリです。既製のカテゴリには、はい / いいえ、痛みと体、文字で伝える、ゲーム、質問、毎日のケア、会議用テンプレート、聴こえのチェック (お使いの言語の名前) と、どの言語でも使える `Spelling_NATO`、`Alert_tones`、`Morse_code` があります。どれもボードを置き換えずに 1 つのカテゴリを追加します。お使いの言語のボードは、起動時と設定で言語を変えたときに、その言語の既定のボードがない場合や変わった場合にここへコピーされ、フォルダー内のコピーを置き換えます。そのため、編集したボードは別の名前で保存してください。
- `%LocalAppData%\SimonSays\debug\`: サポートから求められることがある診断ファイル (`hid_dump.txt` など)。

これらのフォルダーを開くには、パス (例: `%LocalAppData%\SimonSays`) をエクスプローラーのアドレス バーに貼り付けます。

## トラブルシューティング
- **音声の初期化に失敗する**: SAPI がインストールされていて、対応する音声があることを確認してください。
- **自分の言語の音声がない、またはフレーズが違うなまりで話される**: SimonSays は Windows にインストールされている音声を使います。Windows の設定 (**時刻と言語 → 音声 → 音声の管理**) でお使いの言語の音声を追加し、SimonSays の設定 (`F2`) で選んでください。Windows の新しい「ナチュラル」音声の中には、ほかのアプリから使えないものもあります。
- **サウンドが再生されない**: ファイルのパスと拡張子、そして `♫` の区切り文字が対になっていることを確認してください。
- **SimonSays を開いている間、タスク バーが自動的に隠れなくなった**: これは意図した動作です。SimonSays はタスク バーの上にあるので、実行中はタスク バーを表示したままにし、終了するときに「タスク バーを自動的に隠す」を元に戻します。停電などで SimonSays が予期せず終了した場合は、次に SimonSays を終了するときに元に戻ります。
- **ウィジェットのボタンが SimonSays のバーを隠す** (Windows 11): Windows の **設定 → 個人用設定 → タスク バー** でウィジェットをオフにしてください。SimonSays は、初めてウィジェットに気付いたときに、このページを開くかどうかを 1 回だけ尋ねます。
- **カテゴリ ウィンドウが小さすぎる、または大きすぎる**: 空いている場所かウィンドウの端をダブルクリックして内容に合わせるか、`F11` / `F12` でズームしてください。
- **カテゴリやフレーズが消えた**: 設定 (`F2`) の言語を確認してください。言語ごとにボードがあります。インポートでボードが置き換わった場合は、[変更を元に戻す](#変更を元に戻す)を参照してください。
- **「SimonSays はカテゴリとフレーズを保存できませんでした」**: 変更はまだ表示されていますが、SimonSays を閉じると失われる可能性があります。すぐに `F10` でボードをエクスポートして、控えを残してください。くり返し起きる場合はお知らせください。このメッセージは編集のたびではなく 1 回だけ表示されるので、ボードの操作の妨げになることはありません。
- **インポートやエクスポートのエラー**: ファイルのアクセス許可とディスク上の場所を確認して、もう一度試してください。
- **言語や音声の変更が反映されない**: 設定をもう一度開いて選択を確認してください。それでも反映されない場合は、SimonSays を再起動してもう一度試してください。
- **視線追跡装置の問題の報告**: サポートから診断を求められたら、視線 / 注視クリックのウィンドウ (`F3`) を開いて `診断レポートを保存...` をクリックします。レポート (`hid_dump.txt`) は `%LocalAppData%\SimonSays\debug\` に保存され、そのフォルダーが開きます。レポートは、求めたときにだけ作成されます。
