# SimonSays boards

Board files that ship with SimonSays, laid out as:

```
boards\
  <native language name>\        one folder per language, e.g. Español\, 日本語\
    SimonSays_<default phrases>_(<language>).ssc
    SimonSays_<Yes / No>_(<language>).ssc        (localized names)
    SimonSays_<Pain & body>_(<language>).ssc
    SimonSays_<Spelling>_(<language>).ssc        (not in 简体中文\)
    SimonSays_<Games>_(<language>).ssc
    SimonSays_<Questions>_(<language>).ssc
    SimonSays_<Daily care>_(<language>).ssc
    SimonSays_<Hearing check>_(<language>).ssz   (quiet test tones, WAV)
    <Fitzgerald Key board example>_(<language>).ssz   (European languages)
  SimonSays_Spelling_NATO.ssc    language-neutral, for every language
  SimonSays_Alert_tones.ssz
  SimonSays_Morse_code.ssz
```

At startup, and right after the language is changed in Settings, the app copies
the current language's folder plus the language-neutral files into the user's
boards folder, `%LocalAppData%\SimonSays\boards` (flat — the 📂 button opens it),
whenever that language's default board is missing there or out of date
(import-export.spec.md PORT-F41).

## Default phrase boards

`SimonSays_<default phrases>_(<language>).ssc` — the built-in default phrase set
of each language as a whole board. Generated from the app's sources by
`scripts/export_default_boards.ps1`; part of the SimonSays application and
covered by its license (OSL-3.0, see `LICENSE`).

## Ready-made categories

Generated by `scripts/build_extra_boards.ps1` from the data in
`scripts/extra_boards/*.json` — edit the data, then re-run the script; never
edit these files by hand.

Each file holds **one category**, so importing it **adds** that category to the
user's board instead of replacing it. Per-language files carry a `language`
and are refused when SimonSays is set to another language.

| Board | Contents |
|---|---|
| Yes / No | Six large keys: Yes, No, Maybe, I don't know, Wait, Say that again — 18 languages. |
| Pain & body | Where it hurts, what kind of pain, a 0–10 number scale, how it changes, medication and calling for help — 18 languages. |
| Spelling | The language's alphabet and digits, each key showing its letter as the icon beside it, plus spelling-help phrases — 17 languages (not Chinese, which has no alphabet). |
| Games | Turn-taking and game words: your turn, my turn, I pass, dice and cards, rock-paper-scissors, heads/tails, I win, you win, let's play again… — 18 languages. |
| Questions | Who? What? Where? When? Why? How much? What did you say? What time is it? Can you help me?… — 18 languages. |
| Daily care | Hygiene, dressing, transfers, the ventilation mask, suction, cough assist, tube feeding, medicine, massage — complements the default Care & Comfort category. 18 languages. |
| Hearing check | A spoken warning, then quiet test tones at 125 Hz–17.5 kHz for both ears, the left ear only and the right ear only (40 keys). **Not a medical hearing test.** Tones are uncompressed WAV (MP3 would cut the high ones), peak −30 dBFS, 1.5 s, with soft fades — still turn the volume down first, and consider switching off `Increase SimonSays volume when playing` while using it. 18 languages. |
| `SimonSays_Spelling_NATO.ssc` | The NATO phonetic alphabet: each key shows its letter as the icon and speaks its word (Alfa, Bravo…). For any language. |
| `SimonSays_Alert_tones.ssz` | Six emoji-only keys that play tones: chime, "come here", urgent alarm, yes beep, no beep, finished. For any language. |
| `SimonSays_Morse_code.ssz` | A–Z, 0–9, SOS and common prosigns: the letter as the icon beside its code (AR 🔚, SK 👋, BT ⏸️ and Error ❌ get an emoji, with their name in the label), playing its Morse (700 Hz, 20 words per minute). For any language. |

All sounds are synthesized by the build script and encoded to MP3 (44.1 kHz
mono, 64 kbps) with Windows' own encoder, so nothing needs crediting. The 0–10 pain scale is a plain number scale, not any
copyrighted clinical faces scale.

## Fitzgerald Key example board

`<language folder>\<"Fitzgerald Key board example" in that language>_(<language>).ssz`
— a whole example board in the Fitzgerald Key colors (Social, People, Actions,
Nouns, Describing words, Miscellaneous), with 41 pictograms. Importing it
**replaces** the current board (a backup is saved first), as any whole board
does.

- `Español\Ejemplo_de_tablero_Fitzgerald_Key_(Español).ssz` is the hand-made
  original. Edit that one.
- The English, Catalan, Valencian, Basque, Galician, French, German, Italian,
  Portuguese, Brazilian Portuguese and Russian versions are generated from it by
  `scripts/build_extra_boards.ps1` with the translations in
  `scripts/extra_boards/fitzgerald_key.json`: same style, colors and pictures,
  translated texts, title and credits.
